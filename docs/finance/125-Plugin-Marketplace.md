# Plugin Marketplace
## Place de Marché des Extensions
### EduWeb Planner AI Operating System

Version : 1.0

---

# Vision

Le **Plugin Marketplace** est la plateforme officielle de diffusion des extensions d'EduWeb Planner.

Il permet aux établissements, partenaires, développeurs et éditeurs de découvrir, installer, mettre à jour et gérer des plugins certifiés enrichissant les fonctionnalités de l'écosystème EduWeb.

Le Marketplace constitue le point central de distribution de toutes les extensions validées.

---

# Objectifs

Le Marketplace doit permettre de :

- centraliser les extensions ;
- simplifier leur installation ;
- garantir leur sécurité ;
- favoriser l'innovation ;
- développer un écosystème de partenaires ;
- assurer la qualité des plugins publiés.

# Règles métier

## RM-12500

Chaque extension possède un identifiant unique.

---

## RM-12501

Une extension ne peut être publiée qu'après certification.

---

## RM-12502

Chaque installation est journalisée.

---

## RM-12503

Les mises à jour conservent l'historique des versions.

---

## RM-12504

Les évaluations utilisateurs sont modérées conformément aux politiques de la plateforme.

---

## RM-12505

Les extensions retirées restent historisées mais ne sont plus proposées à l'installation.

---

## RM-12506

Le Marketplace vérifie la compatibilité des extensions avant toute installation ou mise à jour.
