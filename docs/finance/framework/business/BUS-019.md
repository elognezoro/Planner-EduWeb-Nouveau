# 1. Introduction

La stratégie ne produit de valeur que lorsqu'elle est transformée en actions concrètes.

La feuille de transformation métier constitue le document qui organise cette évolution.

Elle répond notamment aux questions suivantes :

- Où sommes-nous ?
- Où voulons-nous aller ?
- Quels projets devons-nous réaliser ?
- Dans quel ordre ?
- Avec quelles ressources ?
- Comment mesurer la réussite ?

Elle constitue le principal document de pilotage de la transformation d'EduWeb.

---

# 2. Définition de la feuille de transformation

La feuille de transformation est une planification stratégique décrivant les évolutions nécessaires pour atteindre l'architecture cible.

Elle comprend :

- les programmes ;
- les projets ;
- les priorités ;
- les dépendances ;
- les ressources ;
- les indicateurs.

---

# 3. Vision de la transformation

La transformation d'EduWeb poursuit une ambition simple :

> Construire progressivement une plateforme éducative intelligente, intégrée, internationale et pilotée par les données.

La transformation concerne simultanément :

- les métiers ;
- les organisations ;
- les produits ;
- les processus ;
- les données ;
- les technologies ;
- les compétences.

---

# 4. Objectifs

Cette feuille de route vise à :

- aligner les projets sur la stratégie ;
- maîtriser les investissements ;
- réduire les risques ;
- accélérer les déploiements ;
- améliorer la qualité ;
- garantir une transformation progressive.

---

# 5. Principes directeurs

La transformation suit les principes suivants :

- Business First ;
- Valeur incrémentale ;
- Priorité utilisateur ;
- Architecture pilotée ;
- IA responsable ;
- Données de qualité ;
- Sécurité intégrée ;
- Amélioration continue.

# 7. Analyse de l'état actuel (As-Is)

L'état actuel se caractérise notamment par :

## Points forts

- plateformes opérationnelles ;
- vision stratégique claire ;
- expertise pédagogique ;
- forte capacité d'innovation ;
- architecture déjà largement documentée.

## Axes d'amélioration

- industrialisation ;
- internationalisation ;
- automatisation ;
- gouvernance unifiée ;
- exploitation avancée des données.

---

# 8. Vision cible (To-Be)

À terme, EduWeb disposera :

- d'un écosystème totalement intégré ;
- d'une gouvernance pilotée par les données ;
- d'assistants IA dans tous les produits ;
- d'une architecture API complète ;
- d'une couverture multi-pays ;
- d'une plateforme hautement disponible.

---

# 9. Analyse des écarts (Gap Analysis)

| Domaine | Situation actuelle | Situation cible |
|----------|-------------------|-----------------|
| Gouvernance | Structurée | Gouvernance intégrée |
| IA | Partielle | IA omniprésente |
| Données | Centralisées | Pilotage temps réel |
| Produits | Matures | Plateforme unifiée |
| International | Déploiements limités | Présence multi-pays |
| Décision | Tableaux de bord | Décision prédictive |

Chaque écart donne lieu à un programme de transformation.

# 26. Conclusion

La **Feuille de transformation métier** constitue le document de pilotage stratégique qui relie l'architecture actuelle à l'architecture cible d'EduWeb.

En structurant les programmes, les projets, les dépendances, les priorités, les risques et les mécanismes de gouvernance, elle permet de conduire une transformation progressive, maîtrisée et mesurable.

Cette feuille de route garantit que chaque investissement, chaque évolution produit et chaque initiative organisationnelle contribue directement aux ambitions stratégiques d'EduWeb, tout en limitant les risques et en maximisant la création de valeur pour les établissements, les partenaires et les utilisateurs.

Le document suivant, **BUS-020 — Architecture métier cible**, viendra conclure la collection **BUS** en présentant la synthèse de l'ensemble des architectures métier, leur articulation, la vision intégrée de l'entreprise cible et les principes de fonctionnement de l'écosystème EduWeb dans son état de maturité recherché.
