# 1. Introduction

EduWeb n'est pas une application unique mais un **écosystème de produits numériques** répondant à des besoins complémentaires du secteur éducatif.

Chaque produit constitue une unité de valeur autonome, tout en s'intégrant dans une architecture globale cohérente.

L'architecture produit permet :

- une évolution indépendante ;
- une gouvernance claire ;
- une meilleure réutilisation des composants ;
- une innovation continue ;
- une expérience utilisateur homogène.

---

# 2. Définition d'un produit

Un produit est un ensemble cohérent de services numériques destinés à répondre à un besoin métier identifié.

Un produit possède :

- une vision ;
- une feuille de route (Roadmap) ;
- un Product Owner ;
- des utilisateurs cibles ;
- un cycle de vie ;
- des indicateurs de performance.

---

# 3. Vision produit EduWeb

La vision produit repose sur les principes suivants :

- plateforme intégrée ;
- architecture modulaire ;
- innovation permanente ;
- expérience utilisateur unifiée ;
- intelligence artificielle intégrée ;
- ouverture aux partenaires.

---

# 4. Objectifs

L'architecture des produits vise à :

- structurer l'offre EduWeb ;
- faciliter les évolutions ;
- réduire les duplications ;
- améliorer la gouvernance ;
- optimiser les investissements ;
- accélérer la mise sur le marché.

---

# 5. Principes directeurs

Les produits EduWeb sont conçus selon les principes suivants :

- Product First ;
- API First ;
- Cloud Native ;
- Mobile First ;
- Security by Design ;
- IA responsable ;
- Réutilisation maximale ;
- Évolutivité.

# 9. Produits stratégiques

## EduWeb Planner

Mission :

Optimiser la gestion des établissements scolaires.

Fonctions principales :

- emplois du temps ;
- affectations ;
- gestion des classes ;
- optimisation automatique ;
- statistiques.

---

## EduWeb Governance

Mission :

Digitaliser la gouvernance administrative.

Fonctions :

- actes administratifs ;
- décisions ;
- signatures ;
- workflow ;
- archivage.

---

## EduLex

Mission :

Centraliser les référentiels réglementaires.

Fonctions :

- recherche ;
- veille juridique ;
- diffusion ;
- classification documentaire.

---

# 29. Conclusion

L'**Architecture des produits EduWeb** fournit une vision structurée et cohérente de l'ensemble du portefeuille de solutions numériques de l'écosystème.

En distinguant clairement les produits stratégiques, pédagogiques, administratifs, analytiques et transverses, elle favorise une gouvernance efficace, une meilleure réutilisation des composants et une évolution indépendante de chaque solution tout en maintenant une forte cohérence d'ensemble.

Cette architecture constitue également le socle de la stratégie **Product-Centric** d'EduWeb, où chaque produit dispose d'une vision, d'une feuille de route, d'un responsable identifié et d'indicateurs de performance alignés sur les objectifs de l'entreprise.

Le document suivant, **BUS-012 — Architecture des offres et abonnements**, décrira les différents modèles d'offres commerciales, les formules d'abonnement, les règles de tarification, les mécanismes de souscription et les principes de gestion du cycle de vie des abonnements au sein de l'écosystème EduWeb.
