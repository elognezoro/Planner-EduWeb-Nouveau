# 1. Introduction

Les utilisateurs n'interagissent pas avec une architecture technique ; ils vivent une **expérience**.

Cette expérience résulte de l'ensemble des interactions entre un utilisateur et les services proposés par EduWeb.

La compréhension de ces parcours permet :

- d'améliorer la satisfaction ;
- de réduire les difficultés d'utilisation ;
- d'augmenter l'adoption ;
- de fidéliser les utilisateurs ;
- d'orienter les évolutions fonctionnelles.

---

# 2. Définition du parcours utilisateur

Un parcours utilisateur représente l'ensemble des étapes suivies par un utilisateur afin d'atteindre un objectif donné.

Chaque parcours comprend :

- un déclencheur ;
- des actions ;
- des interactions ;
- des décisions ;
- des émotions ;
- un résultat attendu.

---

# 3. Vision de l'expérience utilisateur

EduWeb adopte une approche centrée sur l'humain.

L'expérience recherchée est :

- simple ;
- fluide ;
- cohérente ;
- sécurisée ;
- inclusive ;
- personnalisée ;
- assistée par l'intelligence artificielle lorsque cela apporte une réelle valeur.

---

# 4. Objectifs

Les parcours utilisateurs visent à :

- réduire les efforts des utilisateurs ;
- améliorer l'accessibilité des services ;
- diminuer les délais d'exécution ;
- accroître la satisfaction ;
- faciliter l'apprentissage de la plateforme ;
- renforcer la fidélisation.

---

# 5. Principes directeurs

Les parcours sont conçus selon les principes suivants :

- User First ;
- Mobile First ;
- Simplicité ;
- Continuité de service ;
- Accessibilité ;
- Personnalisation ;
- Transparence ;
- Amélioration continue.

# 17. Moments de vérité

Les moments de vérité influencent fortement la perception de la qualité.

Ils comprennent notamment :

- création du compte ;
- première connexion ;
- premier emploi du temps généré ;
- première évaluation ;
- premier certificat délivré ;
- première assistance ;
- renouvellement d'abonnement.

Ces étapes doivent être particulièrement soignées.

---

# 18. Frictions et irritants

Les principaux irritants identifiés sont :

- procédures trop longues ;
- saisies répétitives ;
- manque d'accompagnement ;
- difficultés de navigation ;
- lenteur d'affichage ;
- compréhension insuffisante des fonctionnalités.

Chaque irritant est associé à un plan d'amélioration.

---

# 19. Optimisation de l'expérience

Les leviers d'amélioration comprennent :

- simplification des interfaces ;
- automatisation des tâches répétitives ;
- préremplissage intelligent ;
- recherche universelle ;
- tableaux de bord personnalisés ;
- recommandations contextuelles.

---

# 20. Personnalisation

L'interface s'adapte au profil de l'utilisateur.

Exemples :

- menus spécifiques ;
- tableaux de bord dédiés ;
- notifications personnalisées ;
- recommandations adaptées aux usages.

---

# 21. Assistance intelligente

L'assistance repose sur :

- chatbot IA ;
- FAQ intelligente ;
- tutoriels interactifs ;
- recherche sémantique ;
- assistance contextuelle.

L'objectif est de réduire le recours au support humain pour les demandes courantes.

# 29. Conclusion

Les **Parcours utilisateurs** constituent le lien entre les services métier et l'expérience concrète vécue par les utilisateurs de l'écosystème EduWeb.

En décrivant les interactions des chefs d'établissement, enseignants, apprenants, familles, superviseurs, partenaires et administrateurs, cette architecture permet d'identifier les points de contact, les moments clés, les irritants et les opportunités d'amélioration.

L'intégration de mécanismes de personnalisation, d'assistance intelligente et de mesure continue de la satisfaction garantit une expérience fluide, cohérente et évolutive, alignée sur la vision stratégique d'EduWeb.

Le document suivant, **BUS-010 — Architecture des canaux**, décrira les différents canaux d'interaction (web, mobile, API, notifications, assistance, réseaux sociaux, etc.), leur rôle dans l'expérience utilisateur et leur intégration au sein de l'architecture globale d'EduWeb.
