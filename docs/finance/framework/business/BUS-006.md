# 1. Introduction

Le succès d'EduWeb dépend autant de la qualité de ses solutions numériques que de sa capacité à fédérer l'ensemble des acteurs de l'écosystème éducatif.

Chaque acteur possède :

- ses attentes ;
- ses responsabilités ;
- ses contraintes ;
- ses priorités ;
- son niveau d'influence.

Une gestion structurée des parties prenantes favorise :

- l'adhésion ;
- la collaboration ;
- l'innovation ;
- la réussite des projets ;
- la pérennité de la plateforme.

---

# 2. Définition d'une partie prenante

Une partie prenante est toute personne physique ou morale susceptible :

- d'influencer EduWeb ;
- d'être influencée par EduWeb ;
- de bénéficier des services EduWeb ;
- ou de contribuer à leur développement.

Les parties prenantes peuvent être :

- internes ;
- externes ;
- publiques ;
- privées ;
- nationales ;
- internationales.

---

# 3. Vision de la gestion des parties prenantes

EduWeb adopte une approche collaborative fondée sur :

- la transparence ;
- la confiance ;
- la co-construction ;
- la participation ;
- la création de valeur partagée.

L'objectif est de bâtir un véritable **écosystème numérique éducatif**.

---

# 4. Objectifs

Cette cartographie poursuit plusieurs objectifs :

- identifier tous les acteurs ;
- comprendre leurs attentes ;
- analyser leurs interactions ;
- adapter la communication ;
- prioriser les actions ;
- améliorer la gouvernance ;
- réduire les résistances au changement.

---

# 5. Principes directeurs

La gestion des parties prenantes repose sur :

- responsabilité ;
- transparence ;
- respect ;
- inclusion ;
- coopération ;

# 29. Conclusion

La **Cartographie des parties prenantes** fournit une vision structurée de l'ensemble des acteurs qui participent à la réussite d'EduWeb.

En identifiant leurs rôles, leurs responsabilités, leurs attentes, leur niveau d'influence et leurs modes d'interaction, elle facilite une gouvernance collaborative, une communication ciblée et une conduite du changement adaptée aux différents contextes d'utilisation.

Ce référentiel constitue un outil essentiel pour renforcer l'adhésion des utilisateurs, développer des partenariats durables et aligner les décisions stratégiques sur les besoins réels de l'écosystème éducatif.

Le document suivant, **BUS-007 — Organisation et gouvernance métier**, définira l'organisation cible d'EduWeb, les rôles et responsabilités des différentes entités, les instances de gouvernance, les mécanismes de décision et les principes de pilotage garantissant une gestion cohérente et durable de la plateforme.
