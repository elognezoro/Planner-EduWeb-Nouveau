# ALG-018 — Optimisation Prédictive et Prescriptive

> **Objectif :** Définir le moteur d'optimisation prédictive et prescriptive d'EduWeb Planner, capable d'anticiper les perturbations futures, d'en mesurer les impacts et de recommander automatiquement les meilleures décisions avant qu'un problème ne survienne.

# 1. Introduction

Les systèmes traditionnels de génération d'emplois du temps sont essentiellement **réactifs** : ils interviennent lorsqu'un problème est déjà apparu.

EduWeb Planner adopte une approche plus avancée :

- prévoir les événements probables ;
- estimer leurs conséquences ;
- proposer les meilleures décisions avant qu'ils ne surviennent.

L'objectif n'est plus seulement de résoudre un problème, mais de l'éviter.

---

# 2. Pourquoi une optimisation prédictive ?

Les établissements scolaires connaissent des situations récurrentes :

- absences saisonnières ;
- surcharge de certaines périodes ;
- indisponibilité prévisible de salles ;
- examens ;
- activités exceptionnelles ;
- pics d'utilisation des laboratoires.

Le moteur prédictif permet d'anticiper ces situations plusieurs jours ou semaines à l'avance.

---

# 3. Principes directeurs

Le moteur respecte les principes suivants :

- **Predict Before React**
- **Data-Driven Decisions**
- **Human Supervision**
- **Explainable Predictions**
- **Continuous Learning**
- **Risk-Aware Planning**

Toute recommandation reste soumise à une validation humaine.

# 5. Modèles prédictifs

Le moteur exploite plusieurs familles de modèles.

## Prévision des absences

Estimation probabiliste :

- enseignants ;
- salles ;
- équipements.

---

## Prévision des conflits

Identification des périodes où les conflits risquent d'augmenter.

---

## Prévision de charge

Estimation :

- occupation des salles ;
- charge des enseignants ;
- charge des élèves.

---

## Prévision des performances

Le moteur estime l'évolution du score global des emplois du temps.

---

# 6. Optimisation prescriptive

Une fois les prévisions réalisées, le moteur propose automatiquement des actions.

Exemple :

```text
Prévision

↓

Absence probable

↓

Simulation

↓

Recherche de remplaçants

↓

Calcul des impacts

↓

Recommandation
```

Le moteur ne se contente pas de prévoir : il recommande.

---

# 7. Évaluation des risques

Chaque scénario reçoit un indice de risque.

| Niveau | Signification |
|----------|---------------|
| Faible | Aucun impact significatif |
| Modéré | Quelques ajustements nécessaires |
| Élevé | Replanification locale recommandée |
| Critique | Intervention immédiate conseillée |

Les risques sont calculés à partir :

- des contraintes ;
- des historiques ;
- des modèles prédictifs ;
- des indicateurs de qualité.

# 9. Gouvernance

Les recommandations sont :

- journalisées ;
- explicables ;
- versionnées ;
- comparables.

Le système conserve :

- les hypothèses utilisées ;
- les modèles employés ;
- les scénarios évalués ;
- les décisions finalement retenues.

Cette traçabilité facilite les audits et l'amélioration continue.

# 11. Cas d'utilisation

## Préparation de la rentrée

Prévoir les tensions liées :

- aux nouvelles inscriptions ;
- aux recrutements ;
- aux salles disponibles.

---

## Période d'examens

Simulation de plusieurs organisations.

Le moteur recommande automatiquement la plus robuste.

---

## Événement exceptionnel

Avant une sortie pédagogique :

- estimation des impacts ;
- proposition de réorganisation.

---

## Maintenance programmée

Prévoir la fermeture d'un laboratoire.

Le moteur prépare plusieurs scénarios plusieurs jours avant l'intervention.

---

## Pilotage académique

Comparer les risques de plusieurs établissements afin d'anticiper les besoins d'accompagnement.

---

# 12. Perspectives

Les prochaines versions intégreront :

- modèles prédictifs spatio-temporels ;
- réseaux de neurones spécialisés pour la planification ;
- modèles probabilistes bayésiens ;
- prévisions multi-horizons (jour, semaine, trimestre, année) ;
- intégration avec le Digital Twin ;
- recommandations personnalisées par profil utilisateur.

---

# Exemple de scénario

## Situation

Une forte probabilité d'absence est détectée pour un enseignant de Physique.

### Analyse

Le moteur estime :

- probabilité : 82 % ;
- impact : élevé.

### Recommandations

1. Identifier un remplaçant compatible.
2. Réserver un laboratoire alternatif.
3. Préparer deux scénarios de replanification.
4. Informer le chef d'établissement.

Le responsable valide ensuite la solution la plus adaptée.

# Conclusion

L'optimisation prédictive et prescriptive marque une évolution majeure d'EduWeb Planner vers une planification proactive. En exploitant les données historiques, les modèles d'apprentissage automatique, le Jumeau Numérique et les moteurs de simulation, la plateforme est capable d'anticiper les perturbations, d'en évaluer les conséquences et de recommander les décisions les plus pertinentes avant leur survenue. Cette capacité renforce la continuité pédagogique, améliore la qualité des emplois du temps et soutient une gouvernance éducative fondée sur l'analyse prédictive et l'aide intelligente à la décision.
