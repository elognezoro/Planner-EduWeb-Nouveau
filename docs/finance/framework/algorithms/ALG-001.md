# 1. Vision

Le moteur de planification constitue le cœur d'EduWeb Planner.

Il doit être capable de produire automatiquement des emplois du temps :

- cohérents ;
- sans conflit ;
- optimisés ;
- explicables ;
- reproductibles ;
- modifiables.

Le moteur est conçu pour fonctionner sur des établissements de quelques dizaines jusqu'à plusieurs milliers de classes.

---

# 2. Objectifs

Le moteur doit :

✓ supprimer les conflits

✓ respecter toutes les contraintes

✓ minimiser les heures perdues

✓ équilibrer les charges

✓ optimiser les salles

✓ réduire les déplacements

✓ améliorer le confort pédagogique.

---

# 3. Principes

Le moteur suit les principes :

- Constraint Satisfaction Problem (CSP)
- Multi-Objective Optimization
- Explainable Optimization
- Incremental Scheduling
- Human Assisted Planning
- AI Assisted Planning

# 7. Types de contraintes

Le moteur distingue deux catégories.

## Contraintes dures (Hard Constraints)

Obligatoires.

Exemples :

- un enseignant ne peut enseigner deux classes simultanément ;
- une salle ne peut accueillir deux cours simultanément ;
- une classe ne suit qu'un seul cours à la fois ;
- respect des volumes horaires.

Une solution violant une contrainte dure est rejetée.

---

## Contraintes souples (Soft Constraints)

Elles améliorent la qualité.

Exemples :

- éviter les trous ;
- limiter les déplacements ;
- équilibrer les journées ;
- éviter plusieurs cours difficiles successifs ;
- respecter les préférences des enseignants.

# 8. Moteur d'optimisation

Le moteur combine plusieurs familles d'algorithmes.

### CSP

Pour garantir la faisabilité.

---

### Recherche locale

Pour améliorer progressivement la solution.

---

### Metaheuristiques

Selon la taille :

- Recuit simulé
- Recherche tabou
- Algorithmes génétiques
- Colony Optimization

---

### Optimisation exacte

Pour les petits établissements.

- Branch and Bound
- Integer Programming

---

# 9. IA

L'IA intervient uniquement en assistance.

Elle permet :

- proposer une meilleure salle ;
- proposer une permutation ;
- détecter des anomalies ;
- apprendre les préférences historiques.

La validation reste humaine.

# Conclusion

Le moteur d'optimisation constitue le principal avantage concurrentiel d'EduWeb Planner. Son architecture hybride, combinant programmation par contraintes, optimisation multicritère, métaheuristiques et intelligence artificielle explicable, permet de produire des emplois du temps robustes, évolutifs et adaptés à des contextes éducatifs variés.
