# ALG-010 — IA Hybride pour la Génération des Emplois du Temps

> **Objectif :** Définir l'architecture d'intelligence artificielle hybride utilisée par EduWeb Planner pour assister le moteur de planification. Cette IA combine la recherche opérationnelle, les métaheuristiques, le Machine Learning et les modèles d'IA générative afin de produire des emplois du temps robustes, explicables et adaptatifs.

# 1. Introduction

Aucun algorithme unique ne permet aujourd'hui de résoudre efficacement tous les problèmes de planification.

EduWeb Planner adopte donc une **architecture hybride** dans laquelle plusieurs familles d'algorithmes coopèrent.

Cette architecture vise à :

- garantir une solution valide ;
- améliorer progressivement sa qualité ;
- apprendre des générations précédentes ;
- assister les utilisateurs dans leurs décisions.

---

# 2. Pourquoi une IA hybride ?

Chaque approche possède ses forces.

| Technologie | Point fort | Limite |
|-------------|------------|---------|
| CSP | Respect strict des contraintes | Peu optimisé |
| Programmation mathématique | Solutions optimales | Coût élevé |
| Métaheuristiques | Très bonne optimisation | Pas de garantie d'optimalité |
| Machine Learning | Apprentissage | Dépend des données |
| IA générative | Assistance et explication | Ne garantit pas la validité |

L'objectif est de combiner leurs avantages.

---

# 3. Principes directeurs

L'IA d'EduWeb Planner respecte les principes suivants :

- **AI-Assisted, Human-Controlled** ;
- explicabilité des décisions ;
- reproductibilité des résultats ;
- transparence des recommandations ;
- supervision humaine obligatoire pour les décisions critiques.

L'IA ne remplace jamais le responsable des emplois du temps.

# 5. Rôle des différents moteurs

## 5.1 Solveur CSP

Garantit :

- absence de conflits ;
- respect des contraintes réglementaires.

---

## 5.2 Métaheuristiques

Optimisent :

- les déplacements ;
- les heures creuses ;
- l'occupation des salles ;
- le confort pédagogique.

---

## 5.3 Machine Learning

Le Machine Learning apprend notamment :

- les préférences des établissements ;
- les habitudes des enseignants ;
- les corrections manuelles ;
- les modèles historiques.

Il améliore progressivement les générations futures.

---

## 5.4 IA générative

Le modèle de langage intervient uniquement pour :

- expliquer les décisions ;
- suggérer des améliorations ;
- produire des rapports ;
- assister les gestionnaires.

Il ne modifie jamais directement un emploi du temps validé sans contrôle humain.

---

# 7. Apprentissage automatique

Le moteur ML construit progressivement plusieurs modèles.

## Prévision des préférences

Identifier les créneaux généralement retenus.

---

## Détection des conflits récurrents

Repérer les situations fréquemment corrigées.

---

## Optimisation des paramètres

Ajuster automatiquement :

- les poids ;
- les heuristiques ;
- les paramètres des métaheuristiques.

---

## Classement des solutions

Le modèle apprend quelles solutions sont systématiquement choisies par les utilisateurs.

---

# 8. IA générative

Les modèles de langage sont utilisés pour produire :

### Explication des choix

> « Cette séance a été déplacée afin de réduire le nombre d'heures creuses de l'enseignant tout en maintenant la disponibilité du laboratoire. »

---

### Analyse des conflits

Le système explique les causes d'une impossibilité de planification.

---

### Génération de rapports

Production automatique de :

- rapports de génération ;
- synthèses statistiques ;
- comptes rendus d'optimisation.

---

### Assistant conversationnel

Exemples :

> « Pourquoi le laboratoire est-il utilisé à 95 % ? »

ou

> « Propose une meilleure répartition des cours de Mathématiques en Terminale C. »

---

# 9. Explainable AI (XAI)

Toutes les recommandations sont justifiées.

Exemple :

| Décision | Justification |
|-----------|---------------|
| Déplacement du cours | Réduction de 18 % des heures creuses |
| Changement de salle | Meilleure capacité et proximité |
| Réorganisation du mardi | Équilibre des journées amélioré |

Aucune recommandation n'est présentée sans explication.

# 11. Évaluation

Les performances sont mesurées selon plusieurs indicateurs.

| Indicateur | Objectif |
|------------|----------:|
| Taux de conflits | 0 % |
| Satisfaction des préférences | ≥ 90 % |
| Temps moyen de génération | < 2 min |
| Taux d'acceptation des recommandations IA | ≥ 80 % |
| Explications jugées utiles | ≥ 90 % |

Les métriques sont historisées afin de suivre l'évolution du moteur.

---

# 12. Gouvernance

L'utilisation de l'IA respecte les principes suivants :

- protection des données personnelles ;
- journalisation complète des recommandations ;
- possibilité d'audit ;
- validation humaine obligatoire ;
- conformité aux réglementations nationales et internationales.

Les modèles sont versionnés et peuvent être restaurés à tout moment.

---

# 13. Perspectives

Les évolutions prévues comprennent :

- Reinforcement Learning pour la planification adaptative ;
- Graph Neural Networks pour l'analyse des dépendances ;
- AutoML pour le réglage automatique des modèles ;
- IA multimodale (documents, images, règlements) ;
- agents collaboratifs spécialisés (enseignants, salles, contraintes, optimisation) ;
- optimisation distribuée pilotée par IA.

# Conclusion

L'architecture d'**IA hybride** d'EduWeb Planner constitue une évolution majeure des systèmes de planification scolaire. En combinant la rigueur des solveurs de contraintes, la puissance des métaheuristiques, les capacités prédictives du Machine Learning et les fonctions explicatives de l'IA générative, elle permet de produire des emplois du temps fiables, optimisés et transparents. Cette approche garantit un équilibre entre performance algorithmique, supervision humaine et amélioration continue, tout en préparant la plateforme aux futures avancées de l'intelligence artificielle.
