# 1. Introduction

Une plateforme complexe ne peut être exploitée efficacement que si l'on connaît précisément :

- les composants existants ;
- leurs versions ;
- leurs propriétaires ;
- leurs dépendances ;
- leurs relations ;
- leur historique.

La **Configuration Management Database (CMDB)** constitue la mémoire technique de l'ensemble du système d'information.

Elle permet notamment de répondre à des questions essentielles :

- Quels serveurs hébergent EduWeb Planner ?
- Quelle version est actuellement en production ?
- Quels services dépendent de cette base de données ?
- Quels changements impacteront cette API ?
- Quels composants utilisent cette bibliothèque logicielle ?

---

# 2. Vision

EduWeb met en œuvre une CMDB :

- centralisée ;
- dynamique ;
- automatisée ;
- fiable ;
- interconnectée ;
- temps réel ;
- pilotée par les événements.

La CMDB devient la source officielle ("Single Source of Truth") des composants techniques et fonctionnels de l'écosystème EduWeb.

---

# 3. Objectifs

La gestion des configurations poursuit les objectifs suivants :

- disposer d'un inventaire fiable ;
- connaître les dépendances ;
- faciliter les analyses d'impact ;
- sécuriser les changements ;
- améliorer les diagnostics ;
- accélérer les déploiements ;
- renforcer la gouvernance ;
- soutenir les audits.

# 6. Concepts fondamentaux

## Configuration Item (CI)

Tout élément devant être suivi.

Exemples :

- serveur ;
- API ;
- microservice ;
- base de données ;
- application ;
- certificat ;
- équipement réseau ;
- conteneur ;
- modèle IA.

---

## Relation

Lien entre deux Configuration Items.

Exemple :

```text
API

↓

utilise

↓

Base de données
```

---

## Baseline

Photographie officielle de l'état d'un système à une date donnée.

Elle sert de référence lors :

- des audits ;
- des changements ;
- des restaurations.

---

## État

Chaque CI possède un état.

Exemples :

- En développement
- En test
- En préproduction
- En production
- Hors service
- Archivé

# 22. Conclusion

La **Gestion des Configurations (CMDB)** constitue le référentiel de confiance de l'écosystème EduWeb. En centralisant l'ensemble des composants, de leurs versions, de leurs dépendances et de leur historique, elle fournit une vision unifiée indispensable aux activités d'exploitation, de sécurité, d'architecture et de gouvernance.

Intégrée aux processus de gestion des incidents, des problèmes, des changements et aux chaînes **DevSecOps**, la CMDB permet d'améliorer considérablement les analyses d'impact, de réduire les risques opérationnels et d'accélérer les interventions. Associée à la découverte automatique, aux graphes de dépendances et aux capacités d'**AIOps**, elle devient un élément fondamental de la plateforme d'exploitation intelligente d'EduWeb.

Le document suivant (**OPS-008 — Gestion des Versions et Déploiements**) s'appuiera directement sur la CMDB pour assurer la maîtrise des versions logicielles, des stratégies de déploiement et de la continuité des mises en production.
