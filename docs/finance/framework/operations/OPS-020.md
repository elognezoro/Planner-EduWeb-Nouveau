# 1. Introduction

L'ensemble des documents OPS-001 à OPS-019 décrit les différents domaines nécessaires à l'exploitation moderne des plateformes numériques.

Cependant, une architecture d'entreprise nécessite une vision consolidée.

OPS-020 constitue cette synthèse.

Il présente le modèle opérationnel cible permettant d'exploiter durablement les plateformes EduWeb.

---

# 2. Vision cible

L'exploitation cible d'EduWeb repose sur :

- une supervision unifiée ;
- une observabilité complète ;
- des opérations pilotées par les SLO ;

- une intelligence opérationnelle ;
- un Centre d'Exploitation Intelligent ;
- des pratiques DevSecOps ;
- une culture SRE ;
- une architecture Cloud Native ;

# 35. Conclusion

L'**Architecture Opérationnelle Cible** constitue la vision de référence de l'exploitation des plateformes EduWeb.

Elle rassemble dans une architecture cohérente :

```text
Supervision

+

Observabilité

+

ITSM

+

DevSecOps

+

Microservices

+

Cloud

+

AIOps

+

SRE

+

Cybersécurité

+

Automatisation

+

Centre d'Exploitation Intelligent

=

Enterprise Operations Architecture
```

Cette architecture permet à EduWeb de disposer d'un modèle d'exploitation capable de soutenir des plateformes éducatives nationales et internationales, tout en conciliant innovation, sécurité, performance et résilience.

Elle établit un cadre commun pour les équipes techniques, les responsables métiers, les partenaires et les décideurs, assurant une gouvernance homogène et une amélioration continue de la qualité de service.

Avec **OPS-020**, la collection **OPS** est désormais complète. Elle constitue une référence structurée couvrant l'ensemble des dimensions de l'exploitation moderne d'une plateforme numérique d'entreprise et s'intègre naturellement aux autres collections de l'architecture d'entreprise EduWeb (ARCH, ARC, DATA, AI, INT, SEC, ALG, DEC et STD).
