# DEC-018 — Décisions Autonomes Supervisées (Supervised Autonomous Decision Framework)

> **Objectif :** Définir le cadre permettant à la plateforme EduWeb d'exécuter automatiquement certaines décisions à faible risque, tout en garantissant une supervision humaine permanente, une gouvernance rigoureuse et une possibilité d'interruption à tout moment.

# 1. Introduction

Toutes les décisions ne présentent pas le même niveau de criticité.

Certaines opérations sont :

- répétitives ;
- fortement normalisées ;
- peu risquées ;
- parfaitement encadrées par les règles métier.

Dans ces situations, leur automatisation permet :

- d'accélérer les traitements ;
- de réduire les erreurs ;
- d'améliorer la qualité de service ;
- de libérer du temps pour les décisions à forte valeur ajoutée.

En revanche, les décisions stratégiques ou sensibles demeurent sous la responsabilité des décideurs humains.

---

# 2. Vision

EduWeb adopte une approche de **l'autonomie supervisée**.

L'intelligence artificielle peut :

- proposer ;
- préparer ;
- exécuter certaines décisions.

L'humain :

- définit les règles ;
- supervise le système ;
- contrôle les résultats ;
- peut interrompre l'automatisation à tout moment.

L'objectif n'est jamais de supprimer le décideur humain mais d'améliorer son efficacité.

---

# 3. Objectifs

Le cadre poursuit plusieurs objectifs :

- automatiser les décisions répétitives ;
- garantir la conformité réglementaire ;
- maintenir une supervision permanente ;
- assurer une traçabilité complète ;
- réduire les délais de traitement ;
- améliorer la qualité opérationnelle.

---

# 4. Principes directeurs

Le système applique les principes suivants :

- **Human-in-Command**
- **Autonomy Under Supervision**
- **Safety First**
- **Explainability**
- **Auditability**
- **Reversibility**
- **Ethics by Design**
- **Fail Safe**

Une décision automatisée doit toujours pouvoir être suspendue, annulée ou révisée.

# 6. Niveaux d'autonomie

Le système distingue cinq niveaux.

---

## Niveau 0 — Manuel

Toutes les décisions sont prises par un humain.

---

## Niveau 1 — Assistance

L'IA fournit uniquement des recommandations.

---

## Niveau 2 — Validation humaine

L'IA prépare la décision.

L'utilisateur valide avant exécution.

---

## Niveau 3 — Autonomie supervisée

L'IA peut exécuter automatiquement certaines décisions définies à l'avance.

Le superviseur peut :

- surveiller ;
- interrompre ;
- corriger.

---

## Niveau 4 — Autonomie contrôlée

Certaines décisions peuvent être entièrement automatisées dans un domaine limité.

Les contrôles de gouvernance restent obligatoires.

## Autonomous Decision Engine

Décide automatiquement lorsque :

- toutes les conditions sont satisfaites ;
- le niveau de risque est acceptable ;
- le niveau d'autonomie autorisé est atteint.

---

## Execution Manager

---

## Monitoring Engine

- les résultats ;
- les anomalies ;
- les dérives ;
- les incidents.

---

- les performances ;
- les corrections humaines ;

# 9. Conditions d'automatisation

Une décision ne peut être automatisée que si :

- les règles métier sont satisfaites ;
- aucune règle réglementaire n'est violée ;
- le niveau de risque est inférieur au seuil autorisé ;
- le score de confiance est suffisant ;
- les données sont fiables ;
- les validations obligatoires sont présentes.

---

## Exemple

```text
Si

Confiance > 98 %

ET

Risque = Faible

ET

Aucune règle critique violée

Alors

Exécution automatique
```

Sinon :

Validation humaine obligatoire.

---

# 10. Supervision humaine

Le superviseur dispose de plusieurs possibilités.

---

## Validation

Confirmer la décision.

---

## Suspension

Suspendre temporairement le moteur.

---

## Interruption

Arrêter immédiatement une décision en cours.

---

## Révision

Modifier la décision.

---

## Annulation

Revenir sur une décision exécutée lorsque cela est possible.

---

Toutes les interventions sont enregistrées.

---

# 11. Gouvernance

Chaque décision autonome comporte :

- un identifiant ;
- une version des règles ;
- les données utilisées ;
- le niveau d'autonomie ;
- le niveau de confiance ;
- les validations ;
- les journaux d'exécution.

Toutes les décisions sont :

- auditables ;
- explicables ;
- historisées ;
- réversibles lorsque cela est possible.

# Exemple 1 — EduWeb Planner

Une salle devient indisponible.

Le système :

- détecte le problème ;
- recherche automatiquement une salle compatible ;
- met à jour les emplois du temps concernés ;
- informe les utilisateurs.

Aucune validation humaine n'est requise si toutes les règles sont respectées.

---

# Exemple 2 — EduWeb Booking

Une réservation est conforme :

- salle disponible ;
- capacité suffisante ;
- autorisations valides.

La réservation est automatiquement confirmée.

---

# Exemple 3 — EduWeb Governance

Un document administratif satisfait :

- toutes les validations ;
- toutes les signatures ;
- toutes les règles.

Le système publie automatiquement le document.

---

# Exemple 4 — Ministère

Le moteur détecte une incohérence dans une campagne nationale.

Le niveau de risque étant élevé :

- l'exécution est suspendue ;
- une alerte est générée ;
- un responsable est sollicité.

Le système refuse toute automatisation.

# Conclusion

Le **Supervised Autonomous Decision Framework** représente le plus haut niveau d'automatisation opérationnelle envisagé dans l'écosystème EduWeb. Il permet d'exécuter automatiquement les décisions répétitives, bien encadrées et à faible risque, tout en maintenant une gouvernance stricte, une supervision humaine permanente et une traçabilité complète. En combinant règles métier, analyses prédictives, simulations, mécanismes prescriptifs et contrôles de conformité, ce cadre garantit que l'autonomie de l'intelligence artificielle reste toujours maîtrisée, réversible et alignée sur les objectifs institutionnels. Il constitue ainsi une étape essentielle avant la consolidation finale de l'architecture globale de la **Decision Intelligence**, présentée dans les documents DEC-019 et DEC-020.
