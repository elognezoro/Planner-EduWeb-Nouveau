# DEC-005 — Analyse des Impacts (Impact Analysis Engine)

> **Objectif :** Définir le moteur d'analyse des impacts d'EduWeb permettant d'identifier, de mesurer et de visualiser les conséquences potentielles d'une décision avant sa validation, afin d'améliorer la qualité, la robustesse et la transparence des choix effectués.

# 1. Introduction

Toute décision produit des conséquences.

Certaines sont :

- immédiates ;
- différées ;
- positives ;
- négatives ;
- locales ;
- globales.

Avant de recommander une décision, EduWeb doit être capable d'en anticiper les effets.

L'**Impact Analysis Engine** remplit cette fonction.

---

# 2. Objectifs

Le moteur poursuit plusieurs objectifs :

- mesurer les conséquences d'une décision ;
- identifier les effets secondaires ;
- détecter les dépendances ;
- comparer plusieurs scénarios ;
- prévenir les effets indésirables ;
- assister le décideur dans ses arbitrages.

---

# 3. Principes directeurs

Le moteur applique les principes suivants :

- **Impact Before Decision**
- **Global Vision**
- **Systemic Thinking**
- **Predictive Evaluation**
- **Explainability**
- **Human Validation**
- **Continuous Improvement**

Une décision n'est jamais évaluée de manière isolée.

# 8. Calcul des impacts

Chaque impact est évalué selon plusieurs dimensions.

| Critère | Description |
|----------|-------------|
| Intensité | Importance de l'effet |
| Étendue | Nombre d'éléments concernés |
| Durée | Court, moyen ou long terme |
| Probabilité | Chance de réalisation |
| Réversibilité | Possibilité de retour à l'état initial |

Un score global d'impact est ensuite calculé.

Exemple :

| Dimension | Valeur |
|------------|-------:|
| Intensité | 8/10 |
| Étendue | 7/10 |
| Durée | 6/10 |
| Probabilité | 9/10 |
| Réversibilité | 3/10 |

**Score d'impact : 82/100**

# Exemple 1 — EduWeb Planner

## Décision

Déplacer un cours de Mathématiques.

### Impacts détectés

- changement de salle ;
- déplacement d'un enseignant ;
- modification de deux surveillances ;
- augmentation du temps de déplacement des élèves.

Le moteur estime un **impact global moyen**.

# Exemple 2 — EduWeb Governance

## Décision

Modifier une procédure de validation.

### Impacts

- réduction des délais administratifs ;
- diminution du nombre de signatures ;
- modification des responsabilités.

Impact global : **positif**.

# Conclusion

Le **Moteur d'Analyse des Impacts** constitue un composant essentiel de la plateforme décisionnelle d'EduWeb. En évaluant systématiquement les conséquences directes et indirectes de chaque décision, il permet aux responsables d'anticiper les effets sur les dimensions pédagogiques, organisationnelles, humaines, administratives, financières et stratégiques. Couplé aux moteurs d'optimisation, de simulation, d'analyse des risques et de recommandations intelligentes, il contribue à une prise de décision plus robuste, plus transparente et mieux adaptée aux réalités du terrain.
