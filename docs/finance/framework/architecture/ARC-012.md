# ARC-012 — Architecture Intelligence Artificielle

> **Objectif :** Définir l'architecture d'Intelligence Artificielle (IA) d'EduWeb Planner afin d'intégrer des services intelligents, explicables, sécurisés et évolutifs au cœur de la plateforme.

# 1. Vision

L'IA est un accélérateur de décision.

Elle ne remplace jamais les responsables pédagogiques mais les assiste dans leurs décisions.

EduWeb Planner adopte une approche **Human-in-the-Loop**, où toute recommandation importante peut être validée, modifiée ou rejetée par un utilisateur habilité.

---

# 2. Objectifs

L'architecture IA doit permettre :

- l'automatisation des tâches répétitives ;
- l'optimisation des emplois du temps ;
- la détection des anomalies ;
- la prédiction des besoins ;
- l'aide à la décision ;
- l'assistance conversationnelle.

---

# 3. Principes

Les services IA reposent sur les principes suivants :

- Explainable AI (XAI)
- Human-in-the-Loop
- Privacy by Design
- AI by Design
- Modularité
- Auditabilité
- Traçabilité

# 6. Services IA

## AI Gateway

Point d'entrée unique vers les modèles d'IA.

Responsabilités :

- authentification ;
- journalisation ;
- limitation de débit ;
- sélection du fournisseur IA.

---

## Agent Orchestrator

Coordonne plusieurs agents spécialisés.

Exemples :

- Agent Planning
- Agent RH
- Agent Gouvernance
- Agent Reporting
- Agent Support

---

## Scheduler AI

Optimise :

- affectation des enseignants ;
- occupation des salles ;
- contraintes pédagogiques ;
- équilibre des charges.

---

## Analytics AI

Produit :

- recommandations ;
- tendances ;
- prévisions ;
- détection d'anomalies.

---

## Chat Assistant

Répond aux utilisateurs sur :

- les emplois du temps ;
- les statistiques ;
- les règlements ;
- les procédures.

---

# 7. Gouvernance

Chaque modèle IA possède :

- un propriétaire ;
- une version ;
- une documentation ;
- un historique d'entraînement ;
- une politique d'évaluation.

Les modèles sont évalués régulièrement avant leur mise en production.

---

# 8. Explicabilité

Toute recommandation doit pouvoir être expliquée.

Exemple :

> "Cette salle a été choisie car elle satisfait les contraintes de capacité, de disponibilité et de proximité."

L'utilisateur peut consulter les critères ayant conduit à la décision.

---

# 9. Sécurité

Les exigences comprennent :

- anonymisation des données sensibles ;
- chiffrement des échanges ;
- contrôle RBAC ;
- audit des requêtes IA ;
- filtrage des prompts ;
- protection contre les injections de prompts.
