# ARC-008 — Plan de Continuité d'Activité (PCA) & Plan de Reprise d'Activité (PRA)

> **Objectif :** Définir les politiques, processus et moyens permettant d'assurer la continuité des services EduWeb Planner et de restaurer rapidement leur fonctionnement après un incident majeur.

# 1. Vision

EduWeb Planner est un service critique.

Une indisponibilité pendant une période de rentrée scolaire, d'examens ou de publication des emplois du temps peut avoir des conséquences importantes sur plusieurs établissements.

Le PCA garantit la continuité du service.

Le PRA garantit la reprise rapide après un sinistre.

---

# 2. Objectifs

Le PCA/PRA doit permettre :

- maintenir les services essentiels ;
- protéger les données ;
- réduire les interruptions ;
- restaurer rapidement la plateforme ;
- informer les utilisateurs.

---

# 3. Terminologie

## PCA

Ensemble des mesures permettant de maintenir les activités pendant une crise.

---

## PRA

Ensemble des procédures permettant de reconstruire le système après une interruption majeure.

---

## RTO

Temps maximal acceptable pour remettre un service en fonctionnement.

---

## RPO

Perte maximale acceptable de données.

# 7. Scénarios de crise

## Panne d'un serveur

Réaction :

- bascule automatique ;
- redémarrage ;
- notification.

---

## Perte complète d'un centre de données

Réaction :

- activation du site de secours ;
- restauration des services ;
- synchronisation des données.

---

## Attaque ransomware

Réaction :

- isolement des systèmes ;
- restauration depuis sauvegarde saine ;
- rotation des identifiants ;
- audit de sécurité.

---

## Corruption de base de données

Réaction :

- arrêt des écritures ;
- restauration au dernier point cohérent ;
- validation de l'intégrité.

# 9. Sauvegardes

Politique recommandée :

- snapshots horaires ;
- sauvegardes quotidiennes ;
- archivage hebdomadaire ;
- conservation mensuelle.

Règle **3-2-1** :

- 3 copies ;
- 2 supports différents ;
- 1 copie hors site.

Les sauvegardes doivent être chiffrées et testées régulièrement.

---

# 10. Communication de crise

Parties prenantes :

- Direction générale ;
- Équipe DevOps ;
- Support ;
- Établissements ;
- Autorités partenaires.

Canaux :

- e-mail ;
- SMS ;
- WhatsApp ;
- page de statut ;
- portail d'assistance.

Chaque incident doit faire l'objet d'un rapport post-mortem.

---

# 11. Exercices de simulation

Fréquence recommandée :

- test de restauration : mensuel ;
- simulation de panne majeure : trimestrielle ;
- exercice PCA/PRA complet : annuel.

Chaque exercice doit produire :

- un compte rendu ;
- les écarts constatés ;
- les actions correctives.

---

# 12. Gouvernance

| Rôle | Responsabilité |
|------|----------------|

Le PCA/PRA constitue un pilier de la résilience d'EduWeb Planner. En combinant haute disponibilité, sauvegardes, réplication, procédures de crise et exercices réguliers, la plateforme est en mesure d'assurer la continuité des services éducatifs même en cas d'incident majeur.
