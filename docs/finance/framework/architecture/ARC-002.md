# ARC-002 — Architecture métier

> **Objectif :** Décrire l'architecture métier d'EduWeb Planner afin de formaliser les processus, les acteurs, les capacités métier et les interactions qui soutiennent la gestion numérique des établissements scolaires.

# 1. Vision métier

EduWeb Planner est conçu comme une plateforme de gouvernance pédagogique et administrative.

Il ne s'agit pas uniquement d'un générateur d'emplois du temps.

La plateforme couvre progressivement :

- Administration scolaire
- Gestion pédagogique
- Gestion académique
- Pilotage
- Analyse décisionnelle
- Intelligence artificielle
- Collaboration

---

# 2. Principes métier

Les principes suivants orientent toute évolution fonctionnelle.

## Centralisation

Une seule source de vérité.

Toutes les données officielles proviennent d'une base unique.

---

## Numérisation

Toute procédure papier doit pouvoir être digitalisée.

---

## Traçabilité

Chaque action est historisée.

---

## Automatisation

Les tâches répétitives sont automatisées.

---

## Aide à la décision

Les responsables disposent d'indicateurs en temps réel.

# 8. Gouvernance métier

Chaque domaine possède :

- un responsable
- des indicateurs
- des règles
- un cycle de vie

---

# 9. Règles métier

Exemples.

Une salle :

- ne peut accueillir qu'un seul cours simultanément.

Un enseignant :

- ne peut enseigner dans deux salles différentes au même créneau.

Une classe :

- possède un seul emploi du temps officiel.

Un établissement :

- appartient à une seule DRENA.
