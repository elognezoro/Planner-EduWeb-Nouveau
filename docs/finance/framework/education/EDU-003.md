# 1. Introduction

Le curriculum constitue l'ossature de toute formation.

Il organise les connaissances, les compétences, les contenus, les activités et les évaluations afin de conduire progressivement l'apprenant vers la maîtrise des compétences attendues.

L'architecture curriculaire d'EduWeb permet de standardiser cette organisation tout en laissant la possibilité d'adaptations nationales, institutionnelles ou professionnelles.

---

# 2. Finalité du curriculum

Le curriculum permet :

- d'organiser les apprentissages ;
- d'assurer la cohérence des formations ;
- de garantir la progression des compétences ;
- d'harmoniser les pratiques pédagogiques ;
- de faciliter l'évaluation.

---

# 3. Définition

Un curriculum est l'organisation structurée des objectifs, contenus, compétences, méthodes pédagogiques, ressources et évaluations constituant un programme de formation.

---

# 4. Vision

EduWeb adopte une vision selon laquelle chaque curriculum est :

- centré sur les compétences ;
- flexible ;
- évolutif ;
- modulaire ;
- interopérable ;
- compatible avec les standards internationaux.

---

# 5. Principes directeurs

Les curricula EduWeb reposent sur :

- l'approche par compétences ;
- la progressivité ;
- la modularité ;
- la transversalité ;
- l'adaptabilité ;
- l'amélioration continue.

---

# 6. Alignement stratégique

Chaque curriculum est aligné avec :

- les politiques éducatives nationales ;
- les référentiels métiers ;
- les besoins socio-économiques ;
- les compétences du XXIᵉ siècle.

Les formations sont découpées en modules autonomes pouvant être :

- suivis indépendamment ;
- mutualisés ;
- certifiés séparément.

La progression est organisée selon :

- les évaluations.

Les révisions sont programmées :

- les progressions annuelles.

Les plateformes **E-School**, **CERTEL** et **EduWeb Family** s'appuient également sur cette architecture.

# 35. Perspectives

Les évolutions prévues concernent :

- les curricula générés par IA ;
- les micro-certifications ;
- les parcours totalement personnalisés ;
- les référentiels internationaux interopérables.

---

# 36. Synthèse

L'Architecture des Curricula fournit un cadre robuste pour organiser les formations selon une logique modulaire, progressive et orientée compétences. Elle facilite l'adaptation des programmes aux évolutions scientifiques, technologiques et professionnelles tout en garantissant leur cohérence.

---

# 37. Conclusion

L'Architecture des Curricula constitue le socle organisationnel des formations proposées par EduWeb. Elle assure l'alignement entre les objectifs pédagogiques, les référentiels de compétences, les activités d'apprentissage et les modalités d'évaluation, tout en favorisant la modularité et l'évolution continue des programmes.

Le document suivant, **EDU-004 — Architecture des Compétences**, décrira le modèle de structuration, de gestion et d'évaluation des compétences mobilisées dans les différents parcours de formation, ainsi que leur articulation avec les référentiels professionnels et académiques.
