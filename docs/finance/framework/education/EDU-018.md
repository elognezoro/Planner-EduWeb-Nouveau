# 1. Introduction

Un système éducatif national constitue un écosystème complexe composé d’institutions, de politiques publiques, d’acteurs, de programmes, de ressources, de données, de services et d’infrastructures.

Il doit simultanément assurer :

- l’accès à l’éducation ;
- la qualité des apprentissages ;
- l’équité territoriale et sociale ;
- la formation des enseignants ;
- la planification des établissements ;
- l’organisation des examens ;
- la certification ;
- l’orientation ;
- le financement ;
- la production de statistiques ;
- la régulation ;
- la continuité pédagogique ;
- la transformation numérique.

Dans de nombreux contextes, ces fonctions sont portées par des systèmes hétérogènes et peu interopérables.

Cette fragmentation peut produire :

- des doublons ;
- des données contradictoires ;
- des lenteurs administratives ;
- une faible visibilité sur les besoins ;
- des difficultés de planification ;
- une mauvaise allocation des ressources ;
- des retards dans la prise de décision ;
- des inégalités territoriales ;
- une faible traçabilité ;
- une dépendance excessive aux procédures manuelles.

L’Architecture des Systèmes Éducatifs Nationaux d’EduWeb fournit un cadre permettant d’organiser l’ensemble de ces capacités autour d’une vision cohérente, interopérable, sécurisée et pilotée par les données.

# 2. Finalité

Cette architecture vise à :

- aligner les politiques éducatives et les systèmes numériques ;
- renforcer la gouvernance du secteur ;
- structurer les rôles entre niveaux central, régional et local ;
- harmoniser les référentiels ;
- fiabiliser les données nationales ;
- améliorer la planification scolaire ;
- optimiser les ressources ;
- soutenir les établissements ;
- renforcer le suivi des apprentissages ;
- faciliter les examens et certifications ;
- assurer l’équité ;
- soutenir la transformation numérique ;
- améliorer la transparence ;
- garantir la continuité des services éducatifs.

# 3. Définition

L’**Architecture d’un Système Éducatif National** désigne l’ensemble structuré des politiques, institutions, capacités, processus, données, applications, infrastructures et mécanismes de gouvernance permettant de concevoir, organiser, financer, délivrer, superviser et améliorer l’éducation à l’échelle d’un pays.

Elle couvre notamment :

- l’administration centrale ;
- les directions régionales ;
- les inspections ;
- les établissements ;
- les programmes ;
- les enseignants ;
- les apprenants ;
- les examens ;
- les certifications ;
- les infrastructures ;
- les financements ;
- les statistiques ;
- les services numériques ;
- les partenariats.

# 37. Conclusion

L’**Architecture des Systèmes Éducatifs Nationaux** fournit un cadre intégré permettant de relier la politique éducative, la gouvernance, les territoires, les établissements, les enseignants, les apprenants, les familles et les partenaires.

Elle organise les capacités nécessaires à :

- la planification ;
- la gestion des curricula ;
- la gestion des établissements ;
- la gestion des personnels ;
- le suivi des apprenants ;
- l’organisation des examens ;
- la certification ;
- l’inclusion ;
- le financement ;
- la gestion des infrastructures ;
- la production de données ;
- le pilotage national.

Cette architecture permet de dépasser la juxtaposition de systèmes isolés pour construire un écosystème éducatif interopérable, sécurisé et centré sur l’apprenant.

Les plateformes EduWeb peuvent contribuer à cette transformation en apportant des services spécialisés et intégrés :

- EduWeb Planner pour la planification ;
- E-School EduWeb pour l’apprentissage ;
- EduWeb Family pour l’accompagnement ;
- EduWeb Governance pour les textes et procédures ;
- EduWeb Booking pour les ressources ;
- CERTEL pour le développement et la certification des compétences.

La plateforme nationale de données éducatives constitue le socle du pilotage, tandis que la gouvernance, la qualité, la sécurité, la souveraineté et l’inclusion garantissent la durabilité du système.

Le document suivant, **EDU-019 — Transformation Numérique de l’Éducation**, définira les étapes, les programmes, les capacités, les mécanismes de conduite du changement et les feuilles de route nécessaires pour faire évoluer progressivement les systèmes éducatifs traditionnels vers des environnements numériques intégrés, inclusifs et pilotés par les données.
