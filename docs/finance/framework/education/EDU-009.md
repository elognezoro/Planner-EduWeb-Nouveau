# 1. Introduction

Les compétences numériques sont devenues indispensables à la réussite scolaire, universitaire, professionnelle et citoyenne.

Elles ne se limitent pas à la capacité d’utiliser un ordinateur ou un téléphone. Elles comprennent également la capacité à :

- rechercher une information fiable ;
- produire des contenus ;
- communiquer en ligne ;
- protéger ses données ;
- utiliser les outils numériques de manière responsable ;
- résoudre des problèmes ;
- comprendre les usages de l’intelligence artificielle ;
- collaborer dans des environnements numériques ;
- exercer son esprit critique.

L’Architecture des Compétences Numériques d’EduWeb définit un cadre commun permettant de structurer ces compétences, de les intégrer dans les curricula, de les développer à travers des parcours adaptés et de les certifier de manière fiable.

---

# 2. Finalité

Cette architecture vise à :

- réduire la fracture numérique ;
- développer l’autonomie des utilisateurs ;
- soutenir la transformation numérique de l’éducation ;
- améliorer les pratiques pédagogiques ;
- renforcer la sécurité des usages ;
- accompagner l’intégration de l’intelligence artificielle ;
- favoriser l’employabilité ;
- harmoniser les niveaux de maîtrise ;
- faciliter la certification ;
- permettre l’apprentissage tout au long de la vie.

---

# 3. Définition

Une **compétence numérique** est la capacité à mobiliser de manière efficace, critique, responsable et sécurisée des connaissances, des méthodes, des outils et des attitudes dans un environnement numérique.

Elle combine :

- savoirs techniques ;
- savoir-faire pratiques ;
- jugement critique ;
- comportements responsables ;
- capacité d’adaptation ;
- compréhension des risques ;
- autonomie.

---

# 4. Vision

EduWeb promeut une culture numérique dans laquelle chaque acteur de l’éducation est capable de :

- utiliser les technologies avec discernement ;
- comprendre leurs possibilités et leurs limites ;
- protéger les données et les personnes ;
- collaborer efficacement ;
- créer des contenus de qualité ;
- apprendre de manière autonome ;
- intégrer l’intelligence artificielle de façon éthique ;
- contribuer à la transformation numérique de son institution.

Cette vision place les compétences numériques au service de l’éducation, de l’inclusion et du développement humain.

# 11. Culture et environnement numériques

Ce domaine couvre la capacité à :

- identifier les principaux équipements ;
- comprendre le fonctionnement général d’un système numérique ;
- utiliser un système d’exploitation ;
- organiser ses fichiers ;
- installer ou utiliser une application ;
- comprendre les notions de réseau et de cloud ;
- distinguer matériel, logiciel, donnée et service ;
- utiliser les périphériques ;
- adopter de bonnes pratiques d’entretien ;
- comprendre l’impact environnemental du numérique.

Exemples de compétences :

- créer une arborescence de dossiers ;
- sauvegarder un document ;
- utiliser un espace de stockage en ligne ;
- connecter un périphérique ;
- gérer les paramètres essentiels d’un appareil.

# 17. Intelligence artificielle

Les compétences liées à l’intelligence artificielle comprennent :

- comprendre les principes généraux de l’IA ;
- distinguer différents usages ;
- formuler une requête pertinente ;
- vérifier les résultats produits ;
- identifier les risques d’erreur ;
- reconnaître les biais ;
- protéger les données ;
- citer ou déclarer l’usage de l’IA ;
- respecter les règles académiques ;
- conserver la responsabilité humaine ;
- utiliser l’IA pour apprendre et créer ;
- éviter la dépendance cognitive.

Le référentiel distingue notamment :

| Niveau | Capacité attendue |
|---|---|
| Sensibilisation | Identifier un outil d’IA |
| Utilisation guidée | Formuler une requête simple |
| Utilisation autonome | Choisir et contrôler un outil |
| Maîtrise | Intégrer l’IA dans un processus |
| Expertise | Concevoir une gouvernance ou un système IA |

Principes essentiels :

- l’IA assiste sans remplacer le jugement ;
- les résultats doivent être vérifiés ;
- les données sensibles ne doivent pas être exposées ;
- la transparence d’usage doit être assurée ;
- l’intégrité académique doit être préservée.

# 23. Niveaux de maîtrise

Le référentiel EduWeb peut adopter cinq niveaux.

| Niveau | Intitulé | Description |
|---|---|---|
| 1 | Initiation | Réalise des tâches simples avec assistance |
| 2 | Autonomie élémentaire | Réalise des tâches courantes |
| 3 | Maîtrise opérationnelle | Choisit et utilise les outils adaptés |
| 4 | Maîtrise avancée | Résout des problèmes complexes |
| 5 | Expertise et innovation | Conçoit, accompagne et innove |

Chaque niveau doit être associé à :

- des situations ;
- des critères ;
- des preuves ;
- des activités ;
- des évaluations ;
- une certification éventuelle.

```text

Compétence : Analyser des données dans un tableur

Critères : Exactitude, lisibilité, pertinence
```

# 32. Cas d’usage EduWeb

## 32.1 CERTEL

CERTEL peut structurer les compétences numériques selon trois niveaux.

### Niveau 1 — Fondamentaux

- environnement informatique ;
- traitement de texte ;
- tableur ;
- présentation ;
- communication numérique ;
- sécurité de base.

### Niveau 2 — Maîtrise professionnelle

- collaboration ;
- traitement avancé des données ;
- création de contenus ;
- gestion de projet ;
- automatisation ;
- IA appliquée.

# 37. Conclusion

L’**Architecture des Compétences Numériques** fournit à EduWeb un cadre structuré pour préparer les apprenants, les enseignants, les personnels administratifs et les responsables institutionnels aux exigences de la société numérique.

Elle dépasse l’apprentissage instrumental des outils pour intégrer la recherche d’information, la création, la collaboration, la cybersécurité, la citoyenneté numérique, les données et l’intelligence artificielle.

En reliant le diagnostic, les référentiels, les parcours, les activités pratiques, les évaluations et les certifications, EduWeb peut proposer une démarche cohérente de développement des compétences numériques tout au long de la vie.

Cette architecture contribue également à la réduction de la fracture numérique, à l’amélioration de l’employabilité, à la modernisation des pratiques éducatives et au renforcement de la sécurité des usages.

Le document suivant, **EDU-010 — Architecture des Learning Analytics**, définira les mécanismes de collecte, d’analyse, de visualisation et d’exploitation responsable des données d’apprentissage afin d’améliorer les parcours, les interventions pédagogiques et le pilotage des systèmes éducatifs.
