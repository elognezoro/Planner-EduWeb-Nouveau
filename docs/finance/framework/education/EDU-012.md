# 1. Introduction

L’apprentissage hybride combine plusieurs modalités d’enseignement et d’apprentissage dans un même dispositif pédagogique.

Il associe notamment :

- enseignement en présentiel ;
- apprentissage à distance ;
- activités synchrones ;
- activités asynchrones ;
- travail autonome ;
- activités collaboratives ;
- accompagnement humain ;
- ressources numériques ;
- évaluations en ligne ou en salle.

L’hybridation ne consiste pas simplement à ajouter des ressources numériques à un cours classique. Elle suppose une conception pédagogique cohérente dans laquelle chaque modalité remplit une fonction précise.

L’Architecture de l’Apprentissage Hybride d’EduWeb permet d’organiser cette complémentarité en tenant compte :

- des objectifs ;
- des compétences ;
- des profils d’apprenants ;
- des contraintes institutionnelles ;
- de la connectivité ;
- des équipements ;
- de la disponibilité des acteurs ;
- des exigences de qualité.

---

# 2. Finalité

Cette architecture vise à :

- améliorer la flexibilité des apprentissages ;
- renforcer l’autonomie des apprenants ;
- maintenir un accompagnement humain ;
- optimiser le temps en présentiel ;
- élargir l’accès aux ressources ;
- assurer la continuité pédagogique ;
- personnaliser les parcours ;
- développer la collaboration ;
- faciliter la formation continue ;
- améliorer le suivi des apprentissages ;
- adapter les dispositifs aux réalités locales ;
- optimiser les ressources pédagogiques et matérielles.

---

# 3. Définition

L’**apprentissage hybride** est un dispositif pédagogique structuré combinant, dans une même progression, des activités réalisées selon plusieurs modalités :

- en présence physique ;
- à distance ;
- en temps réel ;
- en différé ;
- individuellement ;
- collectivement ;
- avec accompagnement ;
- en autonomie.

L’hybridation implique une articulation planifiée entre ces modalités afin qu’elles contribuent ensemble aux mêmes objectifs d’apprentissage.

---

# 4. Vision

EduWeb promeut un apprentissage hybride :

- centré sur l’apprenant ;
- structuré autour des compétences ;
- flexible ;
- accessible ;
- contextualisé ;
- mobile ;
- inclusif ;
- piloté par les données ;
- soutenu par les enseignants ;
- adapté aux environnements à faible connectivité.

Le numérique doit prolonger et enrichir l’action pédagogique, sans supprimer la relation humaine essentielle à l’apprentissage.

# 9. Typologie des modèles hybrides

| Modèle | Description |
|---|---|
| Présentiel enrichi | Cours en salle complété par des ressources numériques |
| Classe inversée | Contenus étudiés à distance, activités réalisées en présence |
| Rotation | Alternance organisée entre plusieurs ateliers ou modalités |
| Hybride flexible | Choix partiel de la modalité par l’apprenant |
| Hybride simultané | Participants présents et distants dans la même séance |
| Parcours alterné | Séquences successives en présence et à distance |
| Hybride tutoré | Travail à distance accompagné par un tuteur |
| Hybride intensif | Regroupements ponctuels complétés par un parcours distant |
| Hybride mobile | Parcours principalement suivi sur téléphone |
| Hybride hors ligne | Ressources locales avec synchronisation différée |
| Hybride professionnel | Alternance entre formation et activité professionnelle |
| Hybride adaptatif | Modalités ajustées selon les besoins de l’apprenant |

# 13. Répartition des modalités

La répartition doit être réalisée selon la fonction pédagogique.

| Fonction | Modalité privilégiée possible |
|---|---|
| Découverte d’un contenu | Asynchrone |
| Explication complexe | Présentiel ou classe virtuelle |
| Entraînement | En ligne ou atelier |
| Expérimentation | Présentiel ou laboratoire virtuel |
| Collaboration | Présentiel ou espace collaboratif |
| Remédiation | Tutorat individualisé |
| Évaluation formative | En ligne |
| Soutenance | Présentiel ou visioconférence |
| Projet | Modalité mixte |
| Certification | Modalité sécurisée |

Le choix reste dépendant du contexte.

# 14. Articulation présentiel-distance

L’articulation doit rendre les deux dimensions interdépendantes.

Exemple :

```text
Avant le présentiel
   ├── Lecture
   ├── Vidéo
   ├── Questionnaire
   └── Diagnostic
          ↓
Pendant le présentiel
   ├── Clarification
   ├── Activité pratique
   ├── Collaboration
   └── Feedback
          ↓
Après le présentiel
   ├── Consolidation
   ├── Devoir
   ├── Forum
   └── Évaluation
```

Les activités à distance doivent préparer, prolonger ou approfondir les séances en présence.

# 19. Scénarisation pédagogique

Le scénario doit préciser l’enchaînement des activités.

Exemple :

| Séquence | Modalité | Activité | Durée |
|---|---|---|---:|
| 1 | Asynchrone | Vidéo introductive | 15 min |
| 2 | Asynchrone | Quiz diagnostique | 10 min |
| 3 | Présentiel | Étude de cas | 60 min |
| 4 | Synchrone distant | Débriefing | 30 min |
| 5 | Asynchrone | Production individuelle | 45 min |
| 6 | Collaboratif | Coévaluation | 30 min |
| 7 | Présentiel | Évaluation pratique | 60 min |

Le scénario doit également préciser :

- les compétences ;
- les ressources ;
- les interactions ;
- les responsabilités ;
- les évaluations ;
- les alternatives ;
- les traces attendues.

# 20. Gestion du temps pédagogique

Le temps doit être envisagé selon plusieurs dimensions :

- temps synchrone ;
- temps asynchrone ;
- travail personnel ;
- temps collaboratif ;
- accompagnement ;
- évaluation ;
- remédiation ;
- pause ;
- délai de réponse.

La charge totale doit rester réaliste.

```text
Charge totale
   =
Présentiel
   +
Distance synchrone
   +
Distance asynchrone
   +
Travail personnel
   +
Évaluation
```

Une surcharge numérique peut réduire l’engagement et augmenter l’abandon.

# 37. Conclusion

L’**Architecture de l’Apprentissage Hybride** permet à EduWeb d’organiser une continuité cohérente entre les activités en présentiel, les classes virtuelles, les ressources asynchrones, le travail autonome, la collaboration, le tutorat et les évaluations.

Elle évite une juxtaposition désordonnée des modalités en imposant un alignement entre les compétences visées, les activités, les ressources, les interactions et les preuves d’apprentissage.

Cette architecture répond aux besoins de flexibilité, d’inclusion, de personnalisation et de continuité pédagogique tout en tenant compte des réalités de connectivité, d’équipement et d’accompagnement.

En intégrant EduWeb Planner, E-School, EduWeb Family, CERTEL, les classes virtuelles et les Learning Analytics, EduWeb peut proposer des dispositifs hybrides complets, pilotables et évolutifs.

Le document suivant, **EDU-013 — Architecture de l’Apprentissage Adaptatif**, définira les mécanismes permettant d’ajuster les parcours, les ressources, les activités, le rythme et le niveau de difficulté en fonction des acquis, des besoins et de la progression de chaque apprenant.
