# 1. Introduction

Un parcours d’apprentissage représente le chemin structuré suivi par un apprenant pour atteindre un ensemble d’objectifs pédagogiques et développer des compétences déterminées.

Dans un environnement éducatif numérique, le parcours ne se limite plus à une succession uniforme de cours. Il devient dynamique, contextualisé et adaptable aux besoins, aux acquis, au rythme et aux objectifs de chaque apprenant.

L’Architecture des Parcours d’Apprentissage d’EduWeb établit un cadre commun permettant de concevoir, administrer, suivre et améliorer ces cheminements pédagogiques.

---

# 2. Finalité

Cette architecture vise à :

- structurer les apprentissages de manière progressive ;
- relier les activités aux compétences attendues ;
- personnaliser les cheminements ;
- prévenir les ruptures d’apprentissage ;
- faciliter l’accompagnement pédagogique ;
- garantir la traçabilité des acquis ;
- améliorer la réussite et l’engagement.

---

# 3. Définition

Un **parcours d’apprentissage** est un ensemble organisé de modules, de séquences, d’activités, de ressources, d’interactions et d’évaluations permettant à un apprenant d’atteindre des objectifs pédagogiques définis.

Il peut être :

- imposé ;
- recommandé ;
- personnalisé ;
- adaptatif ;
- modulaire ;
- certifiant.

---

# 4. Vision

EduWeb promeut une vision dans laquelle chaque apprenant dispose d’un parcours :

- lisible ;
- accessible ;
- progressif ;
- contextualisé ;
- personnalisable ;
- mesurable ;
- reconnu.

Le parcours doit soutenir l’autonomie sans supprimer l’encadrement humain.

---

# 5. Objectifs stratégiques

Les objectifs stratégiques sont :

- améliorer l’engagement des apprenants ;
- réduire les abandons ;
- faciliter la différenciation pédagogique ;
- renforcer la maîtrise des compétences ;
- offrir une continuité entre apprentissage formel et informel ;
- soutenir l’apprentissage tout au long de la vie ;
- permettre le pilotage par les données.

---

# 6. Principes directeurs

Les parcours EduWeb reposent sur les principes suivants :

- centration sur l’apprenant ;
- alignement pédagogique ;
- progressivité ;
- modularité ;
- flexibilité ;
- inclusion ;
- transparence ;
- traçabilité ;
- intervention humaine responsable ;
- amélioration continue.

# 9. Typologie des parcours

EduWeb distingue plusieurs catégories de parcours.

| Type de parcours | Description |
|---|---|
| Linéaire | Progression selon un ordre obligatoire |
| Modulaire | Modules suivis selon des règles de dépendance |
| Personnalisé | Adapté au profil et aux objectifs |
| Adaptatif | Ajusté automatiquement selon les résultats |
| Hybride | Combinaison de présentiel et de distance |
| Accéléré | Réduction du parcours selon les acquis |
| Remédiatif | Correction ciblée des difficultés |
| Certifiant | Conduit à une reconnaissance formelle |
| Professionnalisant | Orienté vers des compétences métier |
| Libre | Choix autonome parmi plusieurs ressources |

---

# 10. Composants d’un parcours

Chaque parcours comporte au minimum :

- un intitulé ;
- une finalité ;
- un public cible ;
- des compétences visées ;
- des prérequis ;
- une durée indicative ;
- des modules ;
- des activités ;
- des ressources ;
- des évaluations ;
- des règles de progression ;
- des modalités d’accompagnement ;
- une condition d’achèvement ;
- une reconnaissance finale.

---

# 11. Profil initial de l’apprenant

Le profil initial peut intégrer :

- le niveau scolaire ou académique ;
- les acquis antérieurs ;
- les compétences maîtrisées ;
- les besoins particuliers ;
- les objectifs personnels ;
- les contraintes de disponibilité ;
- les préférences d’apprentissage ;
- l’accès aux équipements numériques ;
- la maîtrise linguistique ;
- le contexte socio-éducatif.

Les informations recueillies doivent être pertinentes, proportionnées et protégées.

---

# 12. Diagnostic pédagogique

Le diagnostic initial permet de déterminer le point d’entrée approprié dans le parcours.

Il peut s’appuyer sur :

- des tests de positionnement ;
- des entretiens ;
- des questionnaires ;
- l’analyse de résultats antérieurs ;
- un portfolio ;
- des mises en situation ;
- l’autoévaluation.

```text
Diagnostic
   ├── Compétences maîtrisées
   ├── Compétences partielles
   ├── Lacunes prioritaires
   └── Besoins d’accompagnement
```

---

# 13. Objectifs d’apprentissage

Chaque parcours doit définir des objectifs :

- explicites ;
- observables ;
- mesurables ;
- réalistes ;
- alignés sur les compétences ;
- compréhensibles par l’apprenant.

Exemple :

> À l’issue du parcours, l’apprenant est capable de concevoir, construire et évaluer une séquence pédagogique intégrant un outil numérique pertinent.

---

# 14. Prérequis

Les prérequis peuvent être :

- académiques ;
- disciplinaires ;
- techniques ;
- linguistiques ;
- numériques ;
- méthodologiques ;
- comportementaux.

La plateforme doit distinguer :

- les prérequis obligatoires ;
- les prérequis recommandés ;
- les prérequis pouvant faire l’objet d’une remise à niveau.

---

# 15. Progression pédagogique

La progression organise le passage :

- du simple au complexe ;
- du concret à l’abstrait ;
- du guidé à l’autonome ;
- de la découverte à la maîtrise ;
- de la connaissance à la mobilisation en situation.

Une progression équilibrée alterne :

- acquisition ;
- entraînement ;
- application ;
- transfert ;
- évaluation ;
- consolidation.

---

# 16. Séquençage des apprentissages

Le parcours est décomposé selon la structure suivante :

```text
Parcours
   ├── Bloc de compétences
   │      ├── Module
   │      │      ├── Séquence
   │      │      │      ├── Activité
   │      │      │      └── Évaluation
   │      │      └── Projet
   │      └── Validation
   └── Certification
```

Chaque séquence précise :

- sa durée ;
- ses objectifs ;
- les ressources requises ;
- les activités ;
- les productions attendues ;
- les critères d’évaluation.

---

# 17. Activités d’apprentissage

Les activités peuvent comprendre :

- cours interactifs ;
- exercices ;
- études de cas ;
- résolutions de problèmes ;
- projets ;
- simulations ;
- expérimentations ;
- débats ;
- travaux collaboratifs ;
- enquêtes de terrain ;
- productions multimédias ;
- autoévaluations ;
- évaluations par les pairs.

Chaque activité doit contribuer directement à une compétence ou à un objectif identifié.

---

# 18. Ressources pédagogiques

Les ressources mobilisables sont notamment :

- documents textuels ;
- vidéos ;
- fichiers audio ;
- infographies ;
- animations ;
- manuels numériques ;
- activités H5P ;
- simulations ;
- laboratoires virtuels ;
- exercices interactifs ;
- bases documentaires ;
- outils d’intelligence artificielle encadrés.

Les ressources doivent être :

- pertinentes ;
- actualisées ;
- accessibles ;
- adaptées au niveau ;
- compatibles avec les équipements disponibles.

---

# 19. Modalités d’apprentissage

Les parcours peuvent combiner :

- présentiel ;
- distanciel synchrone ;
- distanciel asynchrone ;
- apprentissage mobile ;
- apprentissage autonome ;
- tutorat individuel ;
- travail collaboratif ;
- classe inversée ;
- apprentissage par projet ;
- apprentissage en situation professionnelle.

---

# 20. Parcours personnalisés

La personnalisation peut porter sur :

- le point d’entrée ;
- l’ordre des modules ;
- le rythme ;
- le niveau de difficulté ;
- les ressources proposées ;
- les activités complémentaires ;
- le type d’accompagnement ;
- les modalités d’évaluation.

La personnalisation ne doit pas affaiblir les objectifs communs ni produire des inégalités de traitement.

---

# 21. Parcours adaptatifs

Un parcours adaptatif évolue selon les performances de l’apprenant.

```text
Activité
   ↓
Résultat observé
   ↓
Analyse
   ├── Maîtrise → activité suivante
   ├── Maîtrise partielle → consolidation
   └── Difficulté → remédiation
```

Les règles d’adaptation doivent être :

- explicables ;
- vérifiables ;
- réversibles ;
- validées pédagogiquement ;
- supervisées par l’enseignant.

---

# 22. Parcours hybrides

Un parcours hybride combine plusieurs environnements d’apprentissage.

| Composante | Exemple |
|---|---|
| Présentiel | Atelier pratique |
| Synchrone à distance | Classe virtuelle |
| Asynchrone | Cours sur la plateforme |
| Travail personnel | Lecture et exercice |
| Collaboration | Projet en groupe |
| Accompagnement | Tutorat en ligne |

Le scénario doit préciser la complémentarité entre les différentes modalités.

---

# 23. Parcours inclusifs

Les parcours doivent prendre en compte :

- les handicaps visuels, auditifs, moteurs ou cognitifs ;
- la faible connectivité ;
- les équipements limités ;
- les besoins linguistiques ;
- les différences de rythme ;
- les situations sociales particulières ;
- les interruptions de scolarité.

Les mesures d’adaptation peuvent inclure :

- transcription ;
- sous-titrage ;
- audiodescription ;
- navigation au clavier ;
- téléchargement hors ligne ;
- contenus allégés ;
- temps supplémentaire ;
- supports alternatifs.

---

# 24. Accompagnement et tutorat

L’accompagnement peut être assuré par :

- l’enseignant ;
- le tuteur ;
- le conseiller pédagogique ;
- le pair ;
- le parent ou responsable légal ;
- un assistant numérique sous supervision.

Le dispositif doit préciser :

- la fréquence des interactions ;
- les canaux de communication ;
- les délais de réponse ;
- les modalités d’alerte ;
- les responsabilités de chaque acteur.

---

# 25. Évaluation dans le parcours

L’évaluation intervient à plusieurs moments.

| Moment | Type d’évaluation | Fonction |
|---|---|---|
| Avant le parcours | Diagnostique | Positionner |
| Pendant | Formative | Réguler |
| Après un module | Sommative | Valider |
| En situation | Authentique | Vérifier le transfert |
| En fin de parcours | Certificative | Reconnaître les acquis |

L’évaluation doit être alignée sur les objectifs, les activités et les compétences visées.

---

# 26. Remédiation pédagogique

La remédiation est déclenchée lorsqu’un écart significatif est détecté.

Elle peut prendre la forme de :

- ressources complémentaires ;
- exercices ciblés ;
- tutorat renforcé ;
- reprise d’une notion ;
- changement de modalité ;
- activité simplifiée ;
- évaluation différée ;
- orientation vers un parcours de consolidation.

```text
Difficulté détectée
        ↓
Diagnostic ciblé
        ↓
Plan de remédiation
        ↓
Nouvelle activité
        ↓
Réévaluation
```

---

# 27. Certification et reconnaissance

L’achèvement d’un parcours peut conduire à :

- une attestation ;
- un certificat ;
- un badge numérique ;
- une microcertification ;
- une unité capitalisable ;
- un diplôme ;
- une reconnaissance d’acquis.

La reconnaissance doit préciser :

- l’identité de l’émetteur ;
- les compétences validées ;
- les critères atteints ;
- la date ;
- le niveau ;
- les preuves associées ;
- les modalités de vérification.

---

# 28. Learning Analytics

Les données du parcours permettent de suivre :

- le taux de progression ;
- le temps consacré ;
- les activités réalisées ;
- les résultats ;
- les compétences maîtrisées ;
- les difficultés récurrentes ;
- le niveau d’engagement ;
- les risques de décrochage.

Les tableaux de bord doivent être adaptés au rôle de l’utilisateur :

- apprenant ;
- enseignant ;
- tuteur ;
- chef d’établissement ;
- administrateur ;
- autorité éducative.

---

# 29. Intelligence artificielle

L’intelligence artificielle peut contribuer à :

- recommander des ressources ;
- adapter le niveau de difficulté ;
- suggérer des activités de remédiation ;
- détecter des signaux de décrochage ;
- générer des exercices ;
- fournir une rétroaction initiale ;
- assister la planification pédagogique.

L’IA ne doit pas :

- décider seule d’une orientation définitive ;
- attribuer automatiquement une certification sensible ;
- remplacer le jugement pédagogique ;
- opacifier les critères de progression ;
- exploiter des données non nécessaires.

---

# 30. Gouvernance des parcours

La gouvernance repose sur plusieurs responsabilités.

| Rôle | Responsabilité |
|---|---|
| Comité pédagogique | Valider les orientations |
| Responsable de programme | Piloter le parcours |
| Expert disciplinaire | Garantir la qualité scientifique |
| Ingénieur pédagogique | Concevoir la scénarisation |
| Enseignant | Mettre en œuvre et réguler |
| Référent qualité | Contrôler la conformité |
| Administrateur | Assurer le fonctionnement numérique |
| Data Steward éducatif | Garantir la qualité des données |

Les parcours doivent être versionnés, documentés et soumis à révision périodique.

---

# 31. Assurance qualité

L’assurance qualité porte sur :

- la cohérence des objectifs ;
- l’alignement activités-évaluations ;
- la pertinence des ressources ;
- l’accessibilité ;
- la faisabilité ;
- la charge de travail ;
- la satisfaction ;
- la réussite ;
- l’équité ;
- l’actualisation des contenus.

Cycle d’amélioration :

```text
Concevoir
   ↓
Déployer
   ↓
Observer
   ↓
Évaluer
   ↓
Corriger
   ↓
Améliorer
```

# 37. Conclusion

L’**Architecture des Parcours d’Apprentissage** transforme les curricula et les référentiels de compétences en expériences pédagogiques concrètes, progressives et mesurables.

Elle permet à EduWeb de proposer des parcours structurés tout en tenant compte des différences de niveau, de rythme, de contexte et d’objectif. Elle organise également les mécanismes de diagnostic, d’accompagnement, d’évaluation, de remédiation et de certification nécessaires à une véritable personnalisation des apprentissages.

L’intégration des Learning Analytics et de l’intelligence artificielle peut renforcer cette personnalisation, à condition de préserver la transparence, l’équité et la responsabilité pédagogique humaine.

Le document suivant, **EDU-006 — Architecture des Ressources Pédagogiques**, décrira le modèle de conception, de production, de classification, de diffusion, de réutilisation et de gouvernance des contenus éducatifs mobilisés dans les différents parcours EduWeb.
