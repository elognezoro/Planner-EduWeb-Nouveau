# EDU-002 — Référentiel Pédagogique

> **Objectif :** Définir le référentiel pédagogique de l'écosystème EduWeb afin d'assurer la cohérence, la qualité et l'amélioration continue des dispositifs de formation, quels que soient les publics, les modalités d'apprentissage ou les plateformes utilisées.

# 1. Introduction

Le référentiel pédagogique constitue la référence commune utilisée pour concevoir, produire, diffuser et améliorer l'ensemble des formations proposées au sein de l'écosystème EduWeb.

Il garantit une homogénéité des pratiques tout en laissant aux établissements et aux formateurs la souplesse nécessaire pour adapter leurs méthodes aux besoins des apprenants.

---

# 2. Finalité du référentiel

Le référentiel poursuit plusieurs objectifs :

- harmoniser les pratiques pédagogiques ;
- garantir la qualité des formations ;
- favoriser l'innovation ;
- faciliter l'évaluation ;
- soutenir la transformation numérique.

---

# 3. Définition

Le référentiel pédagogique est un ensemble structuré de principes, de normes, de méthodes, d'outils et de recommandations servant de cadre à toute activité d'enseignement et d'apprentissage.

---

# 4. Champ d'application

Le référentiel s'applique :

- aux établissements scolaires ;
- aux universités ;
- aux centres de formation ;
- aux plateformes numériques ;
- aux formations professionnelles ;
- aux dispositifs hybrides et à distance.

---

# 5. Vision pédagogique

EduWeb promeut une pédagogie :

- centrée sur l'apprenant ;
- fondée sur les compétences ;
- collaborative ;
- inclusive ;
- numérique ;
- évolutive.

---

# 6. Principes fondateurs

Les principes retenus sont :

- apprentissage actif ;
- autonomie progressive ;
- contextualisation ;
- différenciation ;
- évaluation continue ;
- amélioration permanente.

---

# 7. Valeurs éducatives

Les valeurs portées sont :

- excellence ;
- équité ;
- responsabilité ;
- coopération ;
- créativité ;
- intégrité.

---

# 8. Cadres théoriques

Le référentiel s'appuie notamment sur :

- le constructivisme ;
- le socioconstructivisme ;
- l'approche par compétences ;
- la pédagogie de projet ;
- la pédagogie active ;
- la théorie de la charge cognitive.

---

# 9. Approche par compétences

Chaque formation est structurée autour de compétences observables et évaluables.

Les compétences comprennent :

- connaissances ;
- savoir-faire ;
- savoir-être ;
- capacités de transfert.

---

# 10. Objectifs d'apprentissage

Les objectifs doivent être :

- explicites ;
- mesurables ;
- atteignables ;
- pertinents ;
- limités dans le temps.

---

# 11. Taxonomie de Bloom

Le référentiel adopte la taxonomie révisée :

1. Mémoriser
2. Comprendre
3. Appliquer
4. Analyser
5. Évaluer
6. Créer

Ces niveaux servent de base à la conception des activités et des évaluations.

---

# 12. Conception pédagogique

Toute formation comporte :

- une analyse des besoins ;
- des objectifs ;
- une progression ;
- des activités ;
- des évaluations ;
- une amélioration continue.

---

# 13. Scénarisation des apprentissages

Chaque scénario pédagogique précise :

- les séquences ;
- les ressources ;
- les interactions ;
- les productions attendues ;
- les modalités d'évaluation.

---

# 14. Modalités pédagogiques

Le référentiel prend en charge :

- présentiel ;
- distanciel ;
- hybride ;
- autoformation ;
- classe inversée ;
- microlearning.

---

# 15. Ressources pédagogiques

Les ressources peuvent être :

- documents ;
- vidéos ;
- podcasts ;
- simulations ;
- activités H5P ;
- laboratoires virtuels ;
- études de cas.

---

# 16. Activités d'apprentissage

Les activités recommandées comprennent :

- résolution de problèmes ;
- projets ;
- travaux collaboratifs ;
- débats ;
- expérimentations ;
- études de terrain.

---

# 17. Évaluation des apprentissages

Les évaluations sont conçues pour mesurer :

- les acquis ;
- la progression ;
- les compétences ;
- les performances.

Le référentiel privilégie la complémentarité entre évaluations diagnostiques, formatives et sommatives.

---

# 18. Rétroaction pédagogique

La rétroaction doit être :

- rapide ;
- constructive ;
- individualisée ;
- orientée vers la progression.

---

# 19. Personnalisation des parcours

Les parcours peuvent être adaptés selon :

- le niveau initial ;
- les résultats ;
- les préférences ;
- le rythme d'apprentissage ;
- les objectifs professionnels.

---

# 20. Inclusion et accessibilité

Le référentiel intègre :

- les normes d'accessibilité numérique ;
- les besoins éducatifs particuliers ;
- le multilinguisme ;
- l'égalité d'accès aux ressources.

---

# 21. Numérique éducatif

Le numérique est utilisé pour :

- enrichir les apprentissages ;
- faciliter la collaboration ;
- développer les compétences numériques ;
- améliorer le suivi pédagogique.

---

# 22. Intelligence artificielle en pédagogie

L'IA est mobilisée pour :

- assister les enseignants ;
- générer des exercices ;
- personnaliser les apprentissages ;
- détecter les difficultés ;
- proposer des recommandations.

L'enseignant demeure responsable des décisions pédagogiques.

---

# 23. Learning Analytics

Les données d'apprentissage permettent :

- d'identifier les risques de décrochage ;
- de suivre les progrès ;
- d'évaluer l'efficacité des dispositifs ;
- d'améliorer les formations.

---

# 24. Assurance qualité pédagogique

Les actions qualité comprennent :

- audits pédagogiques ;
- évaluations des formations ;
- enquêtes de satisfaction ;
- révisions périodiques des contenus.

---

# 26. Gouvernance pédagogique

La gouvernance repose sur :

- un comité pédagogique ;
- un comité qualité ;
- un comité innovation ;
- un comité d'architecture éducative.

# 35. Perspectives

Les prochaines évolutions porteront sur :

- les référentiels assistés par l'IA ;
- les compétences du futur ;
- l'apprentissage adaptatif avancé ;
- l'interopérabilité internationale des référentiels.

---

# 36. Synthèse

Le référentiel pédagogique constitue la pierre angulaire de la qualité des dispositifs éducatifs d'EduWeb. Il harmonise les méthodes d'enseignement, les modalités d'évaluation, les parcours de formation et les usages du numérique dans une logique d'amélioration continue.

---

# 37. Conclusion

Le **Référentiel Pédagogique** fournit un cadre commun permettant de concevoir des formations cohérentes, innovantes et centrées sur le développement des compétences. Il assure l'alignement entre les objectifs éducatifs, les pratiques pédagogiques et les solutions numériques mises en œuvre par EduWeb.

Le document suivant, **EDU-003 — Architecture des Curricula**, présentera les méthodes de structuration des programmes de formation, des unités d'enseignement, des modules et des parcours académiques afin d'assurer leur cohérence avec les référentiels de compétences et les besoins des systèmes éducatifs.
