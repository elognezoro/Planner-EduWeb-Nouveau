# 1. Introduction

Les apprenants n’entrent pas dans une formation avec les mêmes acquis, les mêmes difficultés, les mêmes rythmes ni les mêmes objectifs.

Un parcours uniforme peut donc produire :

- de l’ennui chez les apprenants avancés ;
- une surcharge chez les apprenants en difficulté ;
- des abandons ;
- des apprentissages superficiels ;
- une mauvaise utilisation des ressources pédagogiques ;
- une remédiation trop tardive.

L’apprentissage adaptatif vise à ajuster progressivement l’expérience éducative à partir des informations disponibles sur l’apprenant, son activité, ses résultats et son contexte.

Il ne consiste pas à laisser un algorithme décider seul du parcours. Il associe :

- référentiels pédagogiques ;
- règles validées ;
- données d’apprentissage ;
- recommandations ;
- intervention de l’enseignant ;
- évaluations régulières ;
- mécanismes de recours ;
- amélioration continue.

L’Architecture de l’Apprentissage Adaptatif d’EduWeb fournit le cadre nécessaire à cette personnalisation responsable.

---

# 2. Finalité

Cette architecture vise à :

- personnaliser les parcours ;
- détecter rapidement les difficultés ;
- proposer des remédiations ciblées ;
- éviter les répétitions inutiles ;
- ajuster le niveau de difficulté ;
- respecter le rythme de l’apprenant ;
- soutenir l’autonomie ;
- améliorer l’engagement ;
- réduire le décrochage ;
- renforcer la maîtrise des compétences ;
- mieux mobiliser les enseignants et tuteurs ;
- améliorer l’efficacité des ressources éducatives.

---

# 3. Définition

L’**apprentissage adaptatif** est une approche dans laquelle le système éducatif ajuste dynamiquement certains éléments du parcours d’apprentissage selon le profil, les acquis, les réponses, les comportements et les besoins de l’apprenant.

L’adaptation peut concerner :

- l’ordre des modules ;
- le niveau de difficulté ;
- le type de ressource ;
- le nombre d’exercices ;
- le rythme ;
- la durée ;
- les modalités d’accompagnement ;
- les évaluations ;
- les recommandations ;
- les activités de remédiation ;
- les possibilités d’approfondissement.

---

# 4. Vision

EduWeb promeut un apprentissage adaptatif :

- centré sur la réussite ;
- transparent ;
- explicable ;
- fondé sur les compétences ;
- supervisé par les professionnels ;
- respectueux de la liberté pédagogique ;
- accessible ;
- équitable ;
- sécurisé ;
- contextualisé ;
- évolutif ;
- orienté vers l’autonomie.

L’objectif n’est pas d’enfermer l’apprenant dans un profil, mais de lui proposer des chemins de progression adaptés et révisables.

---

# 5. Objectifs stratégiques

Les objectifs stratégiques sont :

- créer un moteur de personnalisation commun aux plateformes EduWeb ;
- intégrer les référentiels de compétences ;
- développer des diagnostics numériques ;
- automatiser certaines remédiations ;
- améliorer les taux d’achèvement ;
- proposer des parcours différenciés ;
- soutenir les enseignants dans la prise de décision ;
- améliorer l’efficacité des contenus ;
- permettre la personnalisation à grande échelle ;
- développer des recommandations pédagogiques explicables ;
- assurer la continuité entre apprentissage, évaluation et accompagnement ;
- réduire les écarts de réussite.

# 11. Profil de l’apprenant

Le profil peut inclure :

- niveau d’étude ;
- compétences déjà validées ;
- résultats antérieurs ;
- besoins particuliers ;
- objectifs ;
- préférences déclarées ;
- langue ;

- disponibilité ;
- équipement ;
- connectivité ;
- historique du parcours ;

- accompagnements reçus.

Le profil ne doit pas contenir de données sans lien direct avec la finalité pédagogique.

Le diagnostic permet d’identifier :

- les prérequis maîtrisés ;
- les lacunes ;
- les compétences partielles ;
- les besoins prioritaires ;
- le niveau d’autonomie ;
- les contraintes techniques ;
- le point d’entrée approprié.

Les instruments peuvent comprendre :

- test de positionnement ;
- autoévaluation ;
- entretien ;
- portfolio ;
- exercice pratique ;
- questionnaire contextuel ;
- analyse des acquis antérieurs.

```text
Diagnostic
   ├── Acquis solides
   ├── Acquis fragiles
   ├── Lacunes
   ├── Préférences déclarées
   └── Contraintes
```

# 15. Modèle pédagogique

Le modèle pédagogique précise :

- les stratégies d’enseignement ;

- les règles de progression ;
- les conditions de remédiation ;
- les conditions d’approfondissement ;
- les formes d’accompagnement ;

Il permet de traduire les principes pédagogiques en règles opérationnelles.

# 16. Modèle de l’apprenant

Le modèle de l’apprenant est une représentation dynamique de son état d’apprentissage.

Il peut inclure :

- niveau estimé par compétence ;
- activités réalisées ;
- erreurs fréquentes ;
- rythme ;
- engagement ;
- besoins de soutien ;
- progression ;
- préférences déclarées ;
- recommandations précédentes ;
- réponses aux remédiations.

```text
Modèle apprenant
   ├── Ce qui est maîtrisé
   ├── Ce qui est en cours
   ├── Ce qui reste à acquérir
   ├── Risques détectés
   └── Prochaine action recommandée
```

Ce modèle doit être régulièrement mis à jour et accessible sous une forme compréhensible.

# 17. Moteur d’adaptation

Le moteur d’adaptation sélectionne ou recommande la prochaine action pédagogique.

Il peut combiner :

- règles explicites ;
- arbres de décision ;
- scores de maîtrise ;
- historique des résultats ;
- modèles statistiques ;
- systèmes de recommandation ;
- intelligence artificielle ;
- validation humaine.

Fonctions principales :

1. analyser le profil ;
2. évaluer l’état de maîtrise ;
3. identifier l’objectif suivant ;
4. sélectionner des options ;
5. appliquer les contraintes ;
6. produire une recommandation ;
7. expliquer la recommandation ;
8. enregistrer la décision ;
9. mesurer son effet.

---

# 18. Règles pédagogiques

Les règles peuvent être exprimées sous forme conditionnelle.

```text
SI score < 50 %
ALORS proposer une ressource de reprise
ET planifier un exercice guidé
```


```text
SI score entre 50 % et 75 %
ALORS proposer une activité de consolidation
```


```text
SI score > 75 %
ET critères essentiels maîtrisés
ALORS autoriser la progression
```


```text
SI trois échecs successifs
ALORS alerter le tuteur
ET suspendre l’adaptation automatique
```

Les règles doivent être :

- documentées ;
- testées ;
- versionnées ;
- validées pédagogiquement ;
- révisées périodiquement.

# 19. Adaptation des parcours

L’adaptation du parcours peut modifier :

- le point d’entrée ;
- l’ordre des modules ;
- le nombre d’activités ;
- les étapes obligatoires ;
- les modules optionnels ;
- les activités de remédiation ;
- les activités d’approfondissement ;
- la durée prévisionnelle ;
- le niveau d’accompagnement.

Exemple :

```text
Parcours standard
   ├── Module 1
   ├── Module 2
   ├── Module 3
   └── Évaluation

Parcours adapté
   ├── Diagnostic
   ├── Module 1 allégé
   ├── Remédiation ciblée
   ├── Module 3
   └── Évaluation
```

Les compétences obligatoires ne doivent pas être supprimées sans règle explicite de reconnaissance des acquis.

# 20. Adaptation des ressources

Le système peut recommander :

- un texte ;
- une vidéo ;
- un podcast ;
- une infographie ;
- une démonstration ;
- une simulation ;
- un exercice guidé ;
- un exemple supplémentaire ;
- une fiche de synthèse ;
- une ressource hors ligne ;
- une ressource multilingue ;
- une version accessible.

Le choix peut dépendre :

- du besoin pédagogique ;
- du niveau de lecture ;
- de la connectivité ;
- du type d’équipement ;
- des résultats précédents ;
- de l’accessibilité ;
- des préférences déclarées.

Une préférence n’est pas une vérité permanente et ne doit pas enfermer l’apprenant dans un seul type de ressource.

# 21. Adaptation des activités

Les activités peuvent varier selon :

- la complexité ;
- le degré de guidage ;
- le nombre d’étapes ;
- le contexte ;
- le mode individuel ou collectif ;
- la durée ;
- le niveau d’autonomie ;
- le type de production ;
- les aides disponibles.

Exemple :

| Niveau | Activité |
|---|---|
| Débutant | Exercice guidé |
| Intermédiaire | Étude de cas structurée |
| Avancé | Problème ouvert |
| Expert | Projet complexe ou tutorat de pairs |

# 22. Adaptation de la difficulté

La difficulté peut être ajustée à partir :

- du taux de réussite ;
- du nombre de tentatives ;
- du temps de réponse ;
- du type d’erreur ;
- de la progression ;
- de la maîtrise des prérequis ;
- du niveau de confiance du modèle.

```text
Activité
   ↓
Résultat
   ├── Trop facile → difficulté supérieure
   ├── Adaptée → progression normale
   └── Trop difficile → activité de soutien
```

L’objectif est de maintenir une difficulté stimulante sans produire de surcharge excessive.

L’adaptation du rythme peut porter sur :

- le nombre d’activités par semaine ;
- les délais ;
- la durée de consultation ;
- les rappels ;
- les pauses ;
- la fréquence du tutorat ;
- les possibilités de reprise ;
- l’accélération après reconnaissance d’acquis.

Le système peut proposer :

- un parcours accéléré ;
- un rythme standard ;
- un rythme aménagé ;
- une pause pédagogique ;
- un calendrier de reprise ;
- une prolongation.

Toute modification importante doit rester visible et validable.

# 24. Adaptation de l’accompagnement

Le niveau d’accompagnement peut évoluer selon les besoins.

| Niveau | Modalité |
|---|---|
| Autonomie | Ressources et autoévaluation |
| Accompagnement léger | Messages et rappels |
| Accompagnement standard | Tutorats programmés |
| Accompagnement renforcé | Suivi fréquent |
| Accompagnement intensif | Intervention personnalisée |

Les déclencheurs peuvent être :

- baisse d’activité ;
- échecs répétés ;
- demande explicite ;
- absence prolongée ;
- risque de décrochage ;
- difficulté technique ;
- situation particulière signalée.

# 25. Évaluation adaptative

L’évaluation adaptative sélectionne les questions selon les réponses précédentes.

```text
Question initiale
      ↓
Réponse analysée
      ↓
Estimation du niveau
      ↓
Question suivante adaptée
      ↓
Nouvelle estimation
      ↓
Résultat final
```

Elle nécessite :

- une banque d’items riche ;
- des niveaux de difficulté calibrés ;
- des règles d’arrêt ;
- des critères de validité ;
- une équivalence des parcours ;
- une analyse statistique ;
- une validation pédagogique ;
- des mécanismes de recours.

Elle peut être utilisée pour :

- le positionnement ;
- la remédiation ;
- l’entraînement ;
- l’évaluation formative ;
- certaines certifications encadrées.

# 26. Recommandation pédagogique

Le système peut recommander :

- une ressource ;
- un exercice ;
- une séance de tutorat ;
- une reprise de module ;
- un projet ;
- un groupe de travail ;
- une classe virtuelle ;
- une évaluation ;
- une pause ;
- un approfondissement ;
- une certification.

Une recommandation doit indiquer :

- ce qui est proposé ;
- pourquoi ;
- à partir de quelles informations ;
- le bénéfice attendu ;
- les alternatives ;
- la possibilité de refuser ;
- la personne pouvant être contactée.

Exemple :

> Une activité de consolidation est recommandée parce que deux critères de la compétence « Analyser des données » restent partiellement maîtrisés.

# 27. Intelligence artificielle

L’intelligence artificielle peut contribuer à :

- estimer la maîtrise ;
- détecter des profils de difficulté ;
- recommander des ressources ;
- classer les erreurs ;
- générer des variantes d’exercices ;
- prévoir un risque de décrochage ;
- personnaliser la rétroaction ;
- identifier les meilleures séquences ;
- optimiser les règles ;
- proposer des parcours.

Les modèles utilisés peuvent inclure :

- systèmes à règles ;
- modèles statistiques ;
- classification ;
- systèmes de recommandation ;
- modèles de connaissance ;
- traitement du langage ;
- modèles génératifs encadrés.

L’IA ne doit pas :

- orienter définitivement un apprenant sans validation humaine ;
- supprimer automatiquement une compétence obligatoire ;
- attribuer seule une certification ;
- sanctionner un apprenant ;
- exploiter des données sans finalité légitime ;
- produire une décision impossible à expliquer.

# 28. Explicabilité et contrôle humain

Chaque adaptation significative doit pouvoir être expliquée.

L’explication doit répondre aux questions suivantes :

- quelle décision a été proposée ?
- quelles données ont été utilisées ?
- quelle règle ou quel modèle a été appliqué ?
- pourquoi cette option a-t-elle été retenue ?
- quelles alternatives existent ?
- qui peut modifier la décision ?
- comment contester la recommandation ?

```text
Donnée observée
      ↓
Règle ou modèle
      ↓
Recommandation
      ↓
Explication
      ↓
Validation humaine
      ↓
Action
```

Les enseignants doivent pouvoir :

- accepter ;
- modifier ;
- différer ;
- annuler ;
- remplacer ;
- documenter une décision.

# 30. Inclusion et équité

L’adaptation doit réduire les obstacles sans créer de discrimination.

Les contrôles portent sur :

- l’équité entre groupes ;
- les écarts de recommandation ;
- les effets de la connectivité ;
- les biais linguistiques ;
- les handicaps ;
- les équipements disponibles ;
- les profils minoritaires ;
- les parcours atypiques ;
- la représentation des données.

Les mesures comprennent :

- ressources accessibles ;
- alternatives hors ligne ;
- contrôle des biais ;
- révision humaine ;
- droit à une modalité non adaptative ;
- accès à l’explication ;
- possibilité de correction du profil ;
- audit régulier.

L’adaptation ne doit pas conduire à réduire les ambitions pédagogiques pour certains publics.

# 33. Cas d’usage EduWeb

## 33.1 E-School EduWeb

E-School peut :

- réaliser un diagnostic ;
- proposer un parcours personnalisé ;
- recommander des ressources ;
- ajuster les exercices ;
- déclencher des remédiations ;
- alerter l’enseignant ;

# 37. Conclusion

L’**Architecture de l’Apprentissage Adaptatif** permet à EduWeb de proposer des parcours plus flexibles, plus pertinents et davantage centrés sur les besoins réels des apprenants.

Elle organise la relation entre les référentiels, les diagnostics, les modèles de compétences, les ressources, les évaluations, les données d’apprentissage et les mécanismes de recommandation.

L’adaptation ne doit cependant pas devenir une automatisation opaque de la pédagogie. Les enseignants, les tuteurs et les responsables pédagogiques doivent conserver la capacité de comprendre, de modifier et de contester les décisions proposées par le système.

En intégrant l’explicabilité, l’équité, la sécurité, la gouvernance des données et la supervision humaine, EduWeb peut développer un apprentissage adaptatif responsable, capable d’améliorer la progression sans réduire l’apprenant à un profil algorithmique.

Le document suivant, **EDU-014 — Architecture de l’IA Pédagogique**, définira les principes, les services, les modèles, les usages, les limites et les mécanismes de gouvernance encadrant l’intégration de l’intelligence artificielle dans les activités d’enseignement, d’apprentissage, d’évaluation et d’accompagnement.
