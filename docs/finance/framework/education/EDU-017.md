# 1. Introduction

L’établissement scolaire constitue l’unité opérationnelle fondamentale du système éducatif.

Il rassemble :

- les apprenants ;
- les enseignants ;
- les personnels administratifs ;
- les responsables pédagogiques ;
- les familles ;
- les autorités éducatives ;
- les partenaires ;
- les ressources matérielles ;
- les services numériques.

Son fonctionnement repose sur une combinaison complexe de processus pédagogiques, administratifs, humains, financiers et techniques.

Dans un contexte de transformation numérique, l’établissement ne peut plus être considéré uniquement comme un ensemble de salles de classe. Il devient un environnement intégré dans lequel circulent :

- des informations ;
- des décisions ;
- des emplois du temps ;
- des ressources pédagogiques ;
- des évaluations ;
- des données d’apprentissage ;
- des communications ;
- des services numériques ;
- des indicateurs de pilotage.

L’Architecture des Établissements Scolaires d’EduWeb définit le cadre permettant de structurer et d’intégrer l’ensemble de ces composantes.

---

# 2. Finalité

Cette architecture vise à :

- améliorer le fonctionnement global des établissements ;
- renforcer la qualité pédagogique ;
- simplifier les processus administratifs ;
- faciliter la coordination des acteurs ;
- améliorer la communication avec les familles ;
- garantir la sécurité des apprenants ;
- optimiser l’utilisation des ressources ;
- soutenir la décision par les données ;
- faciliter l’intégration des plateformes EduWeb ;
- accompagner la transformation numérique ;
- renforcer la transparence ;
- améliorer la continuité des activités.

# 3. Définition

L’**Architecture des Établissements Scolaires** désigne l’ensemble structuré des capacités, des acteurs, des processus, des services, des ressources, des données et des technologies nécessaires au fonctionnement d’un établissement d’enseignement.

Elle couvre notamment :

- la gouvernance ;
- la pédagogie ;
- la scolarité ;
- la vie scolaire ;
- les ressources humaines ;
- les finances ;
- les infrastructures ;
- la communication ;
- les données ;
- la sécurité ;
- les services numériques ;
- l’assurance qualité.

# 4. Vision

EduWeb promeut un établissement scolaire :

- centré sur la réussite de l’apprenant ;
- bien gouverné ;
- inclusif ;
- sécurisé ;
- connecté ;
- piloté par les données ;
- ouvert aux familles ;
- capable d’innover ;
- résilient ;
- interopérable avec les systèmes éducatifs ;
- engagé dans l’amélioration continue.

La vision peut être résumée ainsi :

> Un établissement scolaire moderne doit relier efficacement sa mission éducative, son organisation, ses ressources, ses acteurs et ses outils numériques.

# 37. Conclusion

L’**Architecture des Établissements Scolaires** fournit à EduWeb un cadre intégré pour organiser le fonctionnement pédagogique, administratif, humain, financier et numérique d’un établissement moderne.

Elle relie :

- la gouvernance ;
- le projet d’établissement ;
- les curricula ;
- les emplois du temps ;
- les apprenants ;
- les enseignants ;
- les évaluations ;
- la vie scolaire ;
- les familles ;
- les infrastructures ;
- les documents ;
- les finances ;
- les données ;
- les services numériques.

Cette architecture permet de dépasser les outils isolés pour construire un environnement cohérent dans lequel chaque service contribue à la réussite de l’apprenant et à l’efficacité de l’établissement.

L’intégration d’EduWeb Planner, E-School EduWeb, EduWeb Family, EduWeb Governance et EduWeb Booking constitue le socle applicatif de cette vision.

Les données et les Learning Analytics permettent d’améliorer le pilotage, tandis que la gouvernance, la sécurité, l’inclusion et l’assurance qualité garantissent un usage responsable des technologies.

Le document suivant, **EDU-018 — Architecture des Systèmes Éducatifs Nationaux**, définira les structures, les acteurs, les processus, les référentiels, les flux de données, les mécanismes de gouvernance et les services numériques nécessaires au pilotage intégré d’un système éducatif à l’échelle nationale.
