# 1. Introduction

L’intelligence artificielle transforme progressivement les pratiques éducatives.

Elle peut contribuer à :

- produire des ressources ;
- personnaliser les parcours ;
- proposer des exercices ;
- analyser les résultats ;
- détecter certaines difficultés ;
- fournir des rétroactions ;
- faciliter l’accessibilité ;
- accompagner les enseignants ;
- soutenir les décisions pédagogiques ;
- améliorer le pilotage des formations.

Cependant, son intégration dans l’éducation soulève également des risques importants :

- erreurs factuelles ;
- biais ;
- dépendance cognitive ;
- automatisation excessive ;
- perte d’autonomie ;
- atteinte à la vie privée ;
- fraude académique ;
- opacité des décisions ;
- réduction du rôle de l’enseignant ;
- inégalités d’accès ;
- exposition des mineurs ;
- utilisation non maîtrisée des données.

L’Architecture de l’IA Pédagogique d’EduWeb établit un cadre permettant de mobiliser les capacités de l’IA tout en préservant les objectifs éducatifs, la responsabilité humaine, l’équité et la sécurité.

---

# 2. Finalité

Cette architecture vise à :

- encadrer les usages pédagogiques de l’IA ;
- soutenir les enseignants sans les remplacer ;
- améliorer l’accompagnement des apprenants ;
- personnaliser les apprentissages ;
- renforcer la qualité des ressources ;
- accélérer certaines tâches pédagogiques ;
- améliorer la détection des difficultés ;
- favoriser l’inclusion ;
- sécuriser les données éducatives ;
- garantir l’explicabilité des recommandations ;
- prévenir les usages inappropriés ;
- développer une culture critique de l’IA.

---

# 3. Définition

L’**IA pédagogique** désigne l’ensemble des systèmes d’intelligence artificielle utilisés pour soutenir, améliorer ou automatiser partiellement une activité éducative.

Elle peut intervenir dans :

- la conception pédagogique ;
- la création de contenus ;
- l’accompagnement ;
- l’évaluation ;
- la recommandation ;
- la remédiation ;
- l’analyse des apprentissages ;
- la gestion des parcours ;
- l’orientation ;
- la certification ;
- l’administration pédagogique.

L’IA pédagogique ne constitue pas une pédagogie autonome. Elle reste un outil intégré dans un dispositif éducatif conçu et gouverné par des professionnels.

# 4. Vision

EduWeb promeut une IA pédagogique :

- au service de l’humain ;
- centrée sur la réussite de l’apprenant ;
- contrôlée par l’enseignant ;
- explicable ;
- inclusive ;
- équitable ;
- sécurisée ;
- transparente ;
- contextualisée ;
- proportionnée ;
- interopérable ;
- évaluée en continu.

La vision d’EduWeb peut être résumée ainsi :

> L’intelligence artificielle augmente les capacités pédagogiques de l’enseignant sans se substituer à son jugement, à sa responsabilité ni à la relation éducative.

Les objectifs stratégiques sont :

# 12. Assistant pédagogique pour l’enseignant

L’assistant pédagogique peut aider l’enseignant à :

- formuler des objectifs ;
- préparer une séquence ;
- proposer des activités ;
- adapter une ressource ;
- générer des exercices ;
- produire des variantes ;
- préparer un corrigé ;
- construire une grille ;
- rédiger une rétroaction ;
- analyser des résultats ;
- préparer un support ;
- élaborer une remédiation ;
- différencier les apprentissages.

Exemple de processus :

```text
Besoin de l’enseignant
        ↓
Contexte pédagogique
        ↓
Suggestion de l’IA
        ↓
Révision disciplinaire
        ↓
Adaptation au public
        ↓
Validation
        ↓
Utilisation
```

L’enseignant demeure l’auteur responsable du dispositif final.

# 13. Tuteur intelligent pour l’apprenant

Le tuteur intelligent peut :

- expliquer une notion ;
- poser des questions ;
- guider une résolution ;
- proposer un exemple ;
- fournir un indice ;
- recommander une ressource ;
- aider à planifier le travail ;
- rappeler les objectifs ;
- soutenir la révision ;
- proposer une autoévaluation ;
- orienter vers un enseignant.

Le tuteur ne doit pas fournir systématiquement la réponse finale.

Il doit favoriser :

- le raisonnement ;
- l’autonomie ;
- la métacognition ;
- l’effort ;
- la vérification ;
- le transfert.

```text
Question de l’apprenant
        ↓
Analyse du besoin
        ↓
Indice ou explication
        ↓
Nouvelle tentative
        ↓
Feedback
        ↓
Orientation humaine si nécessaire
```

- proposer une explication différente ;
- sélectionner un exercice ;
- ajuster le niveau ;
- générer une activité guidée ;
- recommander un tutorat ;
- alerter l’enseignant ;
- mesurer l’effet de la remédiation.

Cycle de remédiation :

```text
Difficulté détectée
        ↓
Diagnostic
        ↓
Hypothèse explicative
        ↓
Activité ciblée
        ↓
Réalisation
        ↓
Réévaluation
        ↓
Progression ou intervention humaine
```

# 17. Évaluation assistée par l’IA

L’IA peut assister :

- la génération d’items ;
- la création de variantes ;
- la classification des questions ;
- la correction de réponses fermées ;
- l’analyse initiale de réponses ouvertes ;
- l’identification d’erreurs ;
- la proposition de barèmes ;
- la création de rétroactions ;
- l’analyse statistique des résultats ;
- la détection d’anomalies.

Elle ne doit pas être l’unique décisionnaire pour :

- une certification ;
- un examen à fort enjeu ;
- une orientation définitive ;
- une sanction ;
- une exclusion ;
- une validation professionnelle sensible.

---

# 18. Rétroaction automatisée et supervisée

Une rétroaction générée par l’IA doit être :

- liée aux critères ;
- compréhensible ;
- utile ;
- respectueuse ;
- orientée vers l’amélioration ;
- adaptée au niveau ;
- vérifiable ;
- corrigible par l’enseignant.

Exemple :

```text
Production de l’apprenant
        ↓
Analyse par l’IA
        ↓
Proposition de feedback
        ↓
Vérification humaine
        ↓
Diffusion
        ↓
Nouvelle activité
```

La rétroaction ne doit pas se limiter à déclarer qu’une réponse est correcte ou incorrecte.

# 19. IA conversationnelle éducative

Une IA conversationnelle peut soutenir :

- l’explication ;
- la révision ;
- la préparation ;
- l’entraînement ;
- l’orientation vers des ressources ;
- la simulation d’entretien ;
- la pratique linguistique ;
- la résolution guidée ;
- l’accompagnement méthodologique.

Elle doit respecter des règles spécifiques :

- identifier clairement qu’elle est une IA ;
- ne pas se présenter comme une personne ;
- signaler ses limites ;
- éviter les contenus inappropriés ;
- protéger les données ;
- orienter vers un humain en cas de besoin ;
- conserver un langage respectueux ;
- éviter les relations de dépendance ;
- ne pas prétendre détenir une autorité institutionnelle.

# 20. IA pour l’orientation

L’IA peut aider à :

- explorer des parcours ;
- identifier des prérequis ;
- comparer des formations ;
- analyser des compétences ;
- suggérer des métiers ;
- identifier des besoins de formation ;
- proposer des passerelles ;
- organiser un portfolio ;
- préparer un entretien.

Les recommandations doivent rester :

- indicatives ;
- explicables ;
- non discriminatoires ;
- ouvertes à plusieurs options ;
- accompagnées par un professionnel ;
- modifiables ;
- fondées sur des informations pertinentes.

L’IA ne doit pas décider seule de l’avenir scolaire ou professionnel d’une personne.

# 23. IA et intégrité académique

L’IA peut faciliter des usages non conformes :

- devoir entièrement généré ;
- plagiat ;
- fraude ;
- falsification de sources ;
- production sans apprentissage ;
- substitution du raisonnement ;
- contournement d’évaluation.

Les établissements doivent définir :

- les usages autorisés ;
- les usages soumis à déclaration ;
- les usages interdits ;
- les règles de citation ;
- les modalités de contrôle ;
- les conséquences ;
- les recours ;
- les alternatives pédagogiques.

Exemple de classification :

| Niveau | Usage |
|---|---|
| Autorisé | Recherche d’idées et vérification |
| Autorisé avec déclaration | Reformulation ou assistance |
| Autorisé sous supervision | Production partielle |
| Interdit | Génération intégrale d’une épreuve individuelle |
| Interdit | Usurpation ou falsification |

La prévention doit être privilégiée par rapport à une approche uniquement punitive.

# 26. Ingénierie des requêtes pédagogiques

Une requête pédagogique structurée peut comporter :

1. le rôle attendu ;
2. le public ;
3. le contexte ;
4. l’objectif ;
5. la compétence ;
6. le niveau ;
7. la tâche ;
8. les contraintes ;
9. le format de sortie ;
10. les critères de qualité ;
11. les éléments à éviter ;
12. la demande de vérification.

Exemple :

```text
Rôle : Assistant pédagogique
Public : Enseignants du secondaire
Discipline : Physique-Chimie
Niveau : Troisième
Objectif : Expliquer la poussée d’Archimède
Compétence : Interpréter une expérience
Tâche : Proposer une activité expérimentale
Contraintes : Matériel simple, durée de 30 minutes
Sortie : Objectifs, matériel, protocole, résultats attendus
Vérification : Signaler toute incertitude scientifique
```

Les requêtes utilisées institutionnellement doivent être testées, documentées et versionnées.

# 27. Explicabilité

L’explicabilité permet de comprendre :

- ce que l’IA a proposé ;
- pourquoi elle l’a proposé ;
- quelles données ont été utilisées ;
- quel modèle ou quelle règle a été mobilisé ;
- quel est le niveau de confiance ;
- quelles limites existent ;
- quelles alternatives sont possibles ;
- qui peut intervenir.

Exemple :

> Cette ressource est recommandée parce que l’apprenant a échoué à deux activités liées à la compétence « interpréter un graphique ».

Les explications doivent être adaptées au public :

- apprenant ;
- enseignant ;
- administrateur ;
- auditeur ;
- autorité éducative.

# 28. Contrôle humain

Le contrôle humain doit intervenir avant ou après le traitement selon le niveau de risque.

| Niveau de risque | Contrôle requis |
|---|---|
| Faible | Vérification ponctuelle |
| Modéré | Validation avant diffusion |
| Élevé | Double validation |
| Critique | Décision entièrement humaine |

Les professionnels doivent pouvoir :

- accepter ;
- modifier ;
- annuler ;
- différer ;
- remplacer ;
- contester ;
- documenter ;
- auditer.

```text
Proposition IA
      ↓
Contrôle
   ├── Acceptation
   ├── Modification
   ├── Rejet
   └── Escalade
      ↓
Décision humaine
```

# 29. Éthique et équité

Les principaux risques éthiques sont :

- discrimination ;
- biais culturel ;
- biais linguistique ;
- stigmatisation ;
- profilage excessif ;
- réduction des ambitions ;
- perte d’autonomie ;
- surveillance ;
- exclusion numérique ;
- déshumanisation ;
- dépendance ;
- manipulation.

Les mesures comprennent :

- évaluation des biais ;
- diversité des données ;
- validation par des experts locaux ;
- tests sur plusieurs publics ;
- documentation ;
- participation des utilisateurs ;
- recours ;
- alternatives non automatisées ;
- contrôle des effets ;
- révision périodique.

L’IA pédagogique doit augmenter les possibilités d’apprentissage sans renforcer les inégalités.

- journalisation ;
- filtrage des contenus ;
- prévention des injections ;
- contrôle des requêtes ;

- protection des clés ;
- surveillance ;
- sauvegardes ;

# 37. Conclusion

L’**Architecture de l’IA Pédagogique** permet à EduWeb d’intégrer l’intelligence artificielle dans les activités éducatives de manière cohérente, sécurisée et responsable.

Elle organise les usages liés à la conception pédagogique, à la production de ressources, au tutorat, à l’évaluation, à la personnalisation, à la remédiation, à l’orientation, à l’inclusion et au pilotage.

Cette architecture reconnaît que l’intelligence artificielle peut augmenter les capacités des enseignants et améliorer l’accompagnement des apprenants, mais qu’elle ne peut remplacer la responsabilité pédagogique, le jugement professionnel, la relation humaine ni la décision institutionnelle.

L’explicabilité, la protection des données, le contrôle des biais, la transparence, la sécurité, l’intégrité académique et la supervision humaine constituent donc des exigences fondamentales.

En combinant référentiels pédagogiques, données de qualité, modèles contrôlés, services IA mutualisés et gouvernance institutionnelle, EduWeb peut construire une IA éducative adaptée aux réalités des établissements, des apprenants et des systèmes éducatifs.

Le document suivant, **EDU-015 — Architecture de l’Inclusion Numérique**, définira les principes, les services, les standards et les mécanismes permettant de garantir un accès équitable aux ressources, aux plateformes et aux parcours éducatifs, quels que soient le handicap, le lieu de résidence, la connectivité, la langue, l’équipement ou la situation sociale de l’apprenant.
