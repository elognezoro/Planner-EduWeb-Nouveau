# 1. Introduction

L’évaluation constitue une composante essentielle de tout système éducatif.

Elle ne doit pas être réduite à l’attribution d’une note. Elle permet également :

- d’identifier les acquis ;
- de repérer les difficultés ;
- de guider les apprentissages ;
- de réguler l’enseignement ;
- de valider les compétences ;
- de certifier les résultats ;
- d’améliorer les dispositifs pédagogiques.

Dans l’écosystème EduWeb, les évaluations doivent être conçues comme des dispositifs intégrés aux curricula, aux compétences, aux parcours d’apprentissage et aux ressources pédagogiques.

---

# 2. Finalité

L’Architecture des Évaluations vise à :

- garantir la cohérence entre objectifs, activités et évaluations ;
- mesurer les apprentissages de manière fiable ;
- fournir une rétroaction utile ;
- soutenir la progression de l’apprenant ;
- certifier les compétences acquises ;
- assurer l’équité entre les candidats ;
- sécuriser les épreuves et les résultats ;
- exploiter les données d’évaluation pour améliorer les formations ;
- faciliter la prise de décision pédagogique ;
- harmoniser les pratiques d’évaluation.

---

# 3. Définition

Une **évaluation éducative** est un processus organisé de collecte, d’analyse et d’interprétation d’informations permettant de porter un jugement sur les acquis, les compétences, les progrès ou les besoins d’un apprenant.

Elle comprend généralement :

- un objet à évaluer ;
- des critères ;
- des indicateurs ;
- une situation d’évaluation ;
- un instrument ;
- une production ou une réponse ;
- une méthode de correction ;
- une décision pédagogique.

---

# 4. Vision

EduWeb promeut une évaluation :

- au service des apprentissages ;
- fondée sur des critères explicites ;
- centrée sur les compétences ;

- inclusive ;
- traçable ;
- sécurisée ;
- transparente ;
- assistée par le numérique ;
- supervisée par des professionnels de l’éducation.

La priorité n’est pas uniquement de classer les apprenants, mais de les aider à progresser.

# 9. Typologie des évaluations

| Type | Moment | Fonction |
|---|---|---|
| Diagnostique | Avant l’apprentissage | Identifier les acquis et les besoins |
| Formative | Pendant l’apprentissage | Réguler et faire progresser |
| Sommative | À la fin d’une séquence | Mesurer les acquis |
| Certificative | À la fin d’un parcours | Reconnaître officiellement |
| Pronostique | Avant une orientation | Estimer les chances de réussite |
| Normative | Comparaison à un groupe | Positionner |
| Critériée | Comparaison à des critères | Vérifier la maîtrise |
| Autoévaluation | Par l’apprenant | Développer la métacognition |
| Coévaluation | Entre pairs | Développer le jugement |
| Authentique | En situation complexe | Vérifier le transfert |
| Adaptative | Pendant le test | Ajuster la difficulté |

# 10. Alignement pédagogique

Toute évaluation doit être alignée avec :

- les objectifs d’apprentissage ;
- les compétences visées ;
- les activités réalisées ;
- les ressources étudiées ;
- le niveau taxonomique attendu ;
- les critères de réussite ;
- les conditions réelles d’apprentissage.

Exemple :

```text
Objectif
   ↓
Activité d’apprentissage
   ↓
Situation d’évaluation
   ↓
Preuve attendue
   ↓
Critère de réussite
```

Une évaluation ne doit pas mesurer un apprentissage qui n’a pas été réellement travaillé.

---

# 11. Référentiel d’évaluation

Le référentiel d’évaluation précise :

- les compétences évaluées ;
- les composantes de chaque compétence ;
- les critères ;
- les indicateurs observables ;
- les niveaux de maîtrise ;
- les preuves attendues ;
- les seuils de validation ;
- les règles de compensation ;
- les modalités de recours.

Exemple :

| Compétence | Critère | Indicateur | Niveau attendu |
|---|---|---|---|
| Concevoir une séquence | Cohérence pédagogique | Objectifs, activités et évaluation alignés | Maîtrisé |
| Utiliser un outil numérique | Pertinence de l’usage | Outil adapté au besoin | Maîtrisé |
| Communiquer | Clarté | Message structuré et compréhensible | Satisfaisant |

# 12. Objets évalués

L’évaluation peut porter sur :

- les connaissances ;
- la compréhension ;
- les savoir-faire ;
- les compétences ;
- les attitudes ;
- les productions ;
- les démarches ;
- la capacité de transfert ;
- la collaboration ;
- l’autonomie ;
- la créativité ;
- la résolution de problèmes ;
- les compétences numériques ;
- les compétences professionnelles.

L’objet évalué doit être clairement défini avant la conception de l’épreuve.

---

# 13. Critères et indicateurs

Un critère exprime une qualité attendue.

Un indicateur traduit cette qualité en élément observable.

Exemple :

| Critère | Indicateurs possibles |
|---|---|
| Exactitude | Absence d’erreur, résultat correct |
| Pertinence | Réponse adaptée à la consigne |
| Cohérence | Enchaînement logique |
| Clarté | Expression compréhensible |
| Autonomie | Réalisation sans assistance excessive |
| Créativité | Originalité et pertinence de la solution |
| Maîtrise technique | Utilisation correcte des outils |

Les critères doivent être :

- compréhensibles ;
- observables ;
- mesurables ;
- adaptés au niveau ;
- communiqués aux apprenants lorsque cela est possible.

---

# 14. Niveaux de maîtrise

Une échelle commune peut être utilisée.

| Niveau | Description |
|---|---|
| 1 — Non acquis | La compétence n’est pas démontrée |
| 2 — En cours d’acquisition | La compétence est partiellement mobilisée |
| 3 — Satisfaisant | La compétence est maîtrisée dans une situation connue |
| 4 — Très satisfaisant | La compétence est mobilisée avec autonomie |
| 5 — Expert | La compétence est transférée à des situations complexes |

Les niveaux peuvent être adaptés aux référentiels nationaux ou institutionnels.

# 16. Banque d’items

La banque d’items centralise les questions et situations d’évaluation.

Chaque item doit comporter :

- un identifiant ;
- une discipline ;
- un niveau ;
- une compétence ;
- un objectif ;
- une difficulté estimée ;
- un type de question ;
- une consigne ;
- une réponse attendue ;
- un corrigé ;
- un barème ;
- une durée estimée ;
- une date de validation ;
- un auteur ;
- un statut ;
- un historique d’utilisation.

```text
Banque d’items
   ├── Items en conception
   ├── Items validés
   ├── Items expérimentés
   ├── Items retirés
   └── Items confidentiels
```

# 17. Conception des épreuves

Le processus comprend :

1. définition de la finalité ;
2. sélection des compétences ;
3. élaboration d’une table de spécification ;
4. choix des types d’items ;
5. rédaction ;
6. élaboration du corrigé ;
7. définition du barème ;
8. relecture ;
9. expérimentation ;
10. validation ;
11. sécurisation ;
12. publication.

Une table de spécification peut relier les contenus aux niveaux cognitifs.

| Domaine | Mémoriser | Comprendre | Appliquer | Analyser | Total |
|---|---:|---:|---:|---:|---:|
| Notion A | 2 | 2 | 1 | 0 | 5 |
| Notion B | 1 | 2 | 2 | 1 | 6 |
| Notion C | 1 | 1 | 2 | 2 | 6 |

---

# 18. Validité

La validité indique si l’évaluation mesure réellement ce qu’elle prétend mesurer.

Les dimensions principales sont :

- validité de contenu ;
- validité de construit ;
- validité de critère ;
- validité pédagogique ;
- validité des conséquences.

Les vérifications portent sur :

- la représentativité du contenu ;
- l’alignement avec les objectifs ;
- l’absence de biais ;
- l’adéquation du niveau de difficulté ;
- la cohérence des décisions prises à partir des résultats.

---

# 19. Fidélité et fiabilité

La fidélité exprime la stabilité et la cohérence des résultats.

Elle peut être améliorée par :

- des consignes précises ;
- des conditions d’administration homogènes ;
- des barèmes détaillés ;
- des grilles critériées ;
- la formation des correcteurs ;
- la double correction ;
- la modération ;
- l’analyse statistique des items ;
- la vérification des écarts de notation.

Pour une épreuve importante, la plateforme doit conserver les traces de correction et les décisions de validation.

---

# 20. Équité et inclusion

L’évaluation doit éviter toute discrimination injustifiée.

Les dispositions possibles comprennent :

- temps supplémentaire ;
- format alternatif ;
- lecteur d’écran ;
- transcription ;
- consigne simplifiée sans modification de la compétence visée ;
- salle adaptée ;
- assistance autorisée ;
- police agrandie ;
- version hors ligne ;
- modalité orale ou écrite adaptée.

L’adaptation ne doit pas réduire l’exigence essentielle de la compétence évaluée.

---

L’administration comprend :

- l’inscription des candidats ;
- la planification ;
- la convocation ;
- l’authentification ;
- la distribution des sujets ;
- la gestion du temps ;
- la surveillance ;
- la collecte des productions ;
- la gestion des incidents ;
- la clôture ;
- l’archivage.

```text
Planification
      ↓
Convocation
      ↓
Authentification
      ↓
Passation
      ↓
Collecte
      ↓
Correction
      ↓
Publication
```

Les procédures doivent être adaptées aux évaluations en présentiel, à distance et hybrides.

# 22. Correction et notation

La correction peut être :

- manuelle ;
- automatique ;
- semi-automatique ;
- individuelle ;
- collective ;
- anonyme ;
- modérée ;
- à double correction.

Le barème doit préciser :

- les éléments attendus ;
- les points attribués ;
- les erreurs pénalisantes ;
- les réponses alternatives acceptables ;
- les règles d’arrondi ;
- les seuils de validation.

Pour les productions complexes, une grille critériée est préférable à une simple note globale.

---

# 23. Rétroaction pédagogique

La rétroaction doit aider l’apprenant à comprendre :

- ce qui est réussi ;
- ce qui doit être amélioré ;
- pourquoi une réponse est incorrecte ;
- quelles ressources consulter ;
- quelle activité réaliser ensuite ;
- comment progresser.

Une rétroaction efficace est :

- rapide ;
- précise ;
- constructive ;
- orientée vers l’action ;
- adaptée au niveau ;
- respectueuse ;
- liée aux critères.

---

# 24. Évaluation des compétences

L’évaluation des compétences repose sur des situations permettant de mobiliser plusieurs ressources.

Elle nécessite :

- une situation significative ;
- une production observable ;
- des critères explicites ;
- plusieurs preuves ;
- une appréciation globale ;
- une possibilité de transfert.

Exemple :

```text
Situation professionnelle
        ↓
Mobilisation des connaissances
        ↓
Action ou production
        ↓
Observation des critères
        ↓
Jugement sur la maîtrise
```

Une compétence complexe ne doit pas être validée sur la base d’un seul QCM.

---

# 25. Évaluation authentique

L’évaluation authentique reproduit ou simule une situation réelle.

Exemples :

- concevoir un emploi du temps ;
- élaborer un plan d’action ;
- conduire une séance pédagogique ;
- analyser un dossier administratif ;
- produire un tableau de bord ;
- réaliser une expérimentation scientifique ;
- résoudre une situation professionnelle.

Elle favorise :

- le transfert ;
- l’intégration des acquis ;
- la mobilisation de compétences transversales ;
- la production de preuves concrètes.

---

# 26. Évaluation numérique

L’évaluation numérique peut prendre la forme de :

- quiz en ligne ;
- devoir déposé ;
- activité H5P ;
- examen surveillé à distance ;
- simulation ;
- portfolio numérique ;
- soutenance en visioconférence ;
- projet collaboratif ;
- test mobile ;
- évaluation hors ligne synchronisée.

Les avantages comprennent :

- correction rapide ;
- diversification des médias ;
- traçabilité ;
- adaptation ;
- statistiques automatiques ;
- rétroaction immédiate.

Les risques concernent :

- la fraude ;
- la fracture numérique ;
- les pannes ;
- les erreurs de paramétrage ;
- la perte de données ;
- l’inaccessibilité de certains formats.

---

# 27. Évaluation adaptative

Une évaluation adaptative ajuste la difficulté selon les réponses.

```text
Question initiale
      ↓
Réponse correcte ?
   ├── Oui → item plus complexe
   └── Non → item plus accessible
      ↓
Estimation progressive du niveau
```

Les conditions de mise en œuvre comprennent :

- une banque d’items suffisamment riche ;
- un calibrage statistique ;
- des règles transparentes ;
- une validation pédagogique ;
- des contrôles réguliers ;
- une équivalence des parcours de test.

---

# 28. Intelligence artificielle et évaluation

L’IA peut assister :

- la génération d’items ;
- la création de variantes ;
- la correction initiale ;
- la classification des réponses ;
- la détection d’erreurs récurrentes ;
- la proposition de rétroactions ;
- l’analyse des résultats ;
- la détection de réponses atypiques ;
- la personnalisation de la remédiation.

Toute utilisation de l’IA doit respecter les règles suivantes :

- validation humaine obligatoire ;
- explicabilité suffisante ;
- absence de décision automatique irréversible ;
- contrôle des biais ;
- protection des données ;
- possibilité de recours ;
- journalisation des interventions ;
- vérification de la qualité des corrigés.

L’IA ne doit pas être l’unique correcteur d’une évaluation certificative à fort enjeu.

---

# 29. Sécurité et intégrité académique

Les mesures de sécurité comprennent :

- contrôle d’accès ;
- authentification forte ;
- chiffrement ;
- tirage aléatoire des questions ;
- limitation du temps ;
- journalisation ;
- surveillance ;
- anonymisation des copies ;
- verrouillage des sujets ;
- protection des corrigés ;
- détection du plagiat ;
- contrôle des connexions ;
- sauvegarde automatique ;
- plan de reprise ;
- conservation des preuves.

Les risques principaux sont :

- fuite de sujet ;
- substitution d’identité ;
- fraude ;
- plagiat ;
- modification non autorisée des notes ;
- perte de copies ;
- indisponibilité de la plateforme ;
- correction biaisée ;
- accès illégitime aux résultats.

# 30. Learning Analytics

Les données d’évaluation permettent d’analyser :

- les taux de réussite ;
- les taux d’échec ;
- les items trop faciles ;
- les items trop difficiles ;
- les erreurs récurrentes ;
- les compétences fragiles ;
- les écarts entre groupes ;
- les besoins de remédiation ;
- l’efficacité des parcours ;
- la qualité des questions.

Exemple de tableau de bord :

| Indicateur | Utilité |
|---|---|
| Score moyen | Mesurer la performance globale |
| Taux de réussite par compétence | Identifier les acquis |
| Indice de difficulté | Évaluer les items |
| Taux d’abandon | Détecter les difficultés |
| Temps moyen de réponse | Identifier les questions problématiques |
| Écart entre correcteurs | Vérifier la fidélité |
| Taux de remédiation réussie | Évaluer l’accompagnement |

# 31. Gouvernance

La gouvernance implique plusieurs responsabilités.

| Rôle | Responsabilité |
|---|---|
| Comité d’évaluation | Définit les orientations |
| Responsable pédagogique | Garantit l’alignement |
| Expert disciplinaire | Valide les contenus |
| Concepteur d’items | Produit les questions |
| Responsable de banque d’items | Gère le référentiel |
| Correcteur | Évalue les productions |
| Modérateur | Harmonise les notations |
| Administrateur technique | Sécurise la plateforme |
| Référent qualité | Contrôle les processus |
| Responsable de protection des données | Supervise la conformité |
| Jury | Prend les décisions certificatives |

Les rôles sensibles doivent être séparés autant que possible.

# 32. Assurance qualité

- la conformité au référentiel ;
- la qualité des consignes ;
- la validité des épreuves ;
- la fiabilité des corrections ;
- la sécurité ;
- l’accessibilité ;
- l’équité ;
- le respect des délais ;
- la gestion des recours ;
- l’analyse après passation.

Cycle qualité :

```text
Concevoir
   ↓
Relire
   ↓
Expérimenter
   ↓
Valider
   ↓
Administrer
   ↓
Analyser
   ↓
Améliorer
```

Une revue post-évaluation doit identifier :

- les incidents ;
- les anomalies ;
- les questions contestées ;
- les écarts de correction ;
- les actions correctives ;
- les items à retirer ou réviser.

# 37. Conclusion

L’**Architecture des Évaluations** fournit à EduWeb un cadre cohérent pour concevoir, administrer, corriger, sécuriser et améliorer les dispositifs d’évaluation.

Elle permet de dépasser une approche limitée à la notation en intégrant le diagnostic, la rétroaction, la remédiation, la validation des compétences et la certification. Elle garantit également que les résultats produits sont suffisamment valides, fiables, équitables et traçables pour soutenir les décisions pédagogiques et institutionnelles.

Le numérique, les Learning Analytics et l’intelligence artificielle peuvent améliorer l’efficacité des évaluations, mais leur utilisation doit rester encadrée par des règles de transparence, de sécurité, d’inclusion et de responsabilité humaine.

Le document suivant, **EDU-008 — Architecture des Certifications**, décrira les mécanismes de validation officielle des acquis, de délivrance des certificats, de gestion des badges numériques, de vérification de l’authenticité et de reconnaissance des compétences au sein de l’écosystème EduWeb.
