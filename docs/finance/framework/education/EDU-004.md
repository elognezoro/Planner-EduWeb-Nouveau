# 1. Introduction

Les compétences constituent aujourd'hui le véritable indicateur de réussite d'un parcours éducatif.

L'Architecture des Compétences permet de structurer l'ensemble des savoirs, savoir-faire et savoir-être acquis par les apprenants afin de mieux répondre aux exigences académiques, professionnelles et sociétales.

---

# 2. Finalité

Cette architecture permet :

- d'organiser les compétences ;
- d'assurer leur traçabilité ;
- d'en mesurer la progression ;
- de faciliter leur reconnaissance ;
- de soutenir l'employabilité.

---

# 3. Définition

Une compétence est la capacité démontrée à mobiliser efficacement des connaissances, des habiletés, des attitudes et des ressources pour résoudre une situation donnée.

---

# 4. Vision

EduWeb vise une gestion intégrée des compétences permettant :

- un suivi individuel ;
- une personnalisation des parcours ;
- une certification fiable ;
- une reconnaissance internationale.

---

# 5. Principes directeurs

Les principes sont :

- approche par compétences ;
- progressivité ;
- modularité ;
- mesurabilité ;
- transparence ;
- amélioration continue.

---

# 6. Cadre de référence

L'architecture s'aligne sur :

- les référentiels nationaux ;
- les référentiels métiers ;
- les cadres internationaux de certification ;
- les standards Open Badges.

# 8. Typologie des compétences

Les compétences sont regroupées en plusieurs catégories :

- disciplinaires ;
- transversales ;
- professionnelles ;
- numériques ;
- comportementales.

---

# 9. Compétences disciplinaires

Elles concernent la maîtrise des savoirs propres à chaque discipline.

Exemples :

- mathématiques ;
- physique ;
- langues ;
- informatique ;
- sciences humaines.

---

# 10. Compétences transversales

Elles sont mobilisables dans tous les contextes :

- communication ;
- résolution de problèmes ;
- créativité ;
- esprit critique ;
- collaboration.

---

# 11. Compétences numériques

Elles couvrent notamment :

- culture numérique ;
- cybersécurité ;
- bureautique ;
- intelligence artificielle ;
- programmation ;
- données.

---

# 12. Compétences professionnelles

Elles préparent l'insertion professionnelle :

- gestion de projet ;
- management ;
- relation client ;
- leadership ;
- innovation.

---

# 13. Compétences comportementales

Les soft skills comprennent :

- autonomie ;
- responsabilité ;
- éthique ;
- adaptabilité ;
- gestion du stress ;
- travail en équipe.

---

# 33. Perspectives

Les évolutions porteront sur :

- les passeports de compétences internationaux ;
- les badges intelligents ;
- les référentiels alimentés par l'IA ;
- les compétences émergentes (IA, cybersécurité, durabilité).

---

# 34. Glossaire

- **Compétence** : capacité à mobiliser des ressources dans une situation donnée.
- **Référentiel** : ensemble structuré de compétences.
- **Badge numérique** : preuve numérique d'une compétence acquise.
- **Portfolio** : recueil des réalisations d'un apprenant.

---

# 35. Bonnes pratiques

- Mettre à jour régulièrement les référentiels.
- Associer chaque compétence à des critères mesurables.
- Diversifier les méthodes d'évaluation.
- Favoriser l'autoévaluation et la coévaluation.
- Valoriser les compétences acquises hors du cadre scolaire.

---

# 36. Synthèse

L'Architecture des Compétences permet de structurer, suivre et valoriser les acquis des apprenants tout au long de leur parcours. Elle constitue un levier majeur pour l'amélioration de la qualité des formations, la personnalisation des apprentissages et la reconnaissance des compétences dans les environnements académiques et professionnels.

---

# 37. Conclusion

L'Architecture des Compétences représente le cœur du modèle pédagogique d'EduWeb. Elle assure une gestion cohérente des compétences depuis leur définition jusqu'à leur certification, en s'appuyant sur des référentiels normalisés, des évaluations rigoureuses et des outils numériques avancés.

Grâce à l'intégration des Learning Analytics, de l'intelligence artificielle et des passeports numériques de compétences, EduWeb favorise une approche centrée sur le développement réel des capacités des apprenants et leur employabilité.

Le document suivant, **EDU-005 — Architecture des Parcours d'Apprentissage**, décrira la structuration des parcours de formation, leur personnalisation, leur adaptation aux profils des apprenants et leur articulation avec les référentiels de compétences.
