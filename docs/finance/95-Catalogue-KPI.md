# Catalogue des Indicateurs de Performance (KPI)
## EduWeb Planner

Version : 1.0

---

# Objectif

Le présent document définit le référentiel officiel des indicateurs de performance (KPI) utilisés dans EduWeb Planner.

Les KPI permettent :

- le pilotage stratégique ;
- le suivi opérationnel ;
- l'aide à la décision ;
- l'amélioration continue ;
- les comparaisons entre établissements ;
- les analyses prédictives alimentées par l'IA.

Tous les tableaux de bord utilisent exclusivement les indicateurs définis dans ce catalogue.

---

# Structure d'un KPI

Chaque indicateur est défini par :

- Identifiant unique
- Nom
- Description
- Objectif
- Formule de calcul
- Source de données
- Fréquence de calcul
- Responsable
- Seuils d'alerte
- Niveau d'affichage
- Type de visualisation

---

# Tableaux de bord

Les KPI sont répartis selon les profils :

- Direction Générale
- Administrateur national
- DRENA
- Établissement
- Comptable
- Gestionnaire
- Responsable RH
- Responsable pédagogique
- Administrateur système

Chaque profil ne visualise que les indicateurs autorisés.

---

# Alertes

Chaque KPI peut comporter :

- seuil normal ;
- seuil de vigilance ;
- seuil critique.

Le franchissement d'un seuil peut déclencher :

- notification ;
- e-mail ;
- SMS ;
- alerte dans le tableau de bord ;
- recommandation IA.

---

# Intelligence artificielle

Le moteur IA exploite les KPI pour :

- détecter les tendances ;
- prévoir les évolutions ;
- expliquer les écarts ;
- proposer des actions correctives ;
- générer des rapports automatiques.

---

# Historisation

Chaque indicateur conserve :

- sa valeur ;
- sa date de calcul ;
- son historique ;
- sa méthode de calcul ;
- son origine.

---

# Règles métier

# Tests

Le système devra vérifier :

✓ exactitude des calculs ;

✓ cohérence des agrégations ;

✓ historisation ;

✓ alertes ;

✓ performances ;

✓ droits d'accès.

---

# KPI du catalogue

Le catalogue lui-même est piloté par :

- nombre de KPI actifs ;
- taux de calcul réussi ;
- temps moyen de calcul ;
- nombre d'alertes générées ;
- taux d'utilisation dans les tableaux de bord.

---

# Évolutions prévues

Le système devra intégrer :

- KPI personnalisables par établissement ;
- benchmarking entre établissements ;
- tableaux de bord prédictifs ;
- simulation d'impact de décisions ;
- score global de performance institutionnelle ;
- score de maturité numérique ;
- score de qualité pédagogique.

---

# Conclusion

Le catalogue des KPI constitue le référentiel unique des indicateurs de performance d'EduWeb Planner. Il garantit une mesure homogène, fiable et traçable des activités de la plateforme, tout en fournissant les bases nécessaires à la gouvernance, à l'amélioration continue et aux analyses prédictives assistées par l'intelligence artificielle.
